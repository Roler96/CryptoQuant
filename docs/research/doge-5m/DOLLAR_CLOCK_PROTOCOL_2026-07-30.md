## 0. 假说与它要回答的问题

本仓库对 DOGE 做过十几轮单资产择时研究，全部失败，且诊断反复落在三堵墙上：功效墙（右尾极宽，毛收益打不过同期随机持有）、成本墙（换手外生，15 bps/边吞掉毛 edge）、样本墙（事件触发器把 46 万根 bar 压成几十到几百个稀疏样本）。

**核心论断**：这些不是十几个独立的失败，而是同一个结构问题的反复显影——所有策略都活在同一个坐标系里：**日历时间 × 收盘价 × 常数成本**。

**D 阶段只回答一个问题**：把同一段数据从日历时钟换到成交额时钟，可预测性是否有增量？

不涉及收益、仓位、成本，不产出任何策略。**失败也是结论**：若换了坐标系老问题依然 null，DOGE 现货 5m 可判终局关闭，这是新增证据，而非第 16 个换汤不换药的浅模板。

## 1. 数据契约（实测值，已冻结）

| 项 | 值 |
|---|---|
| 标的 / 周期 | `DOGE-USDT` / `5m`（**仅此一路，不引入永续、BTC、funding、OI**） |
| 窗口 | explore 窗 `ts ∈ [2021-01-01, 2025-06-01)` |
| 载入根数 | **464,256**（= 1612 天 × 288，连续性断言通过） |
| 对齐后根数 | **464,255** |
| 数据指纹 | **`12b8ca59c15fc519`**（SHA256 前 16 hex，覆盖 ts + OHLCV 六列） |

- **validate 窗不碰**。runner 不导入也不调用 `forward_holdout` / `record_holdout_access`。
- 使用列：`ts, high, low, close, volume, quote_volume`。`open` 不作为特征，仅供健全性交叉检验。
- **连续性断言**：根数必须同时满足「相邻间隔恒为 300,000 ms」与「等于按请求窗口算出的期望根数 464,256」。任一不符即拒跑上报，不做近似填补。第二项是必要的：仅凭载入数据自身首尾推算是自证，尾部被截断也会通过。
- **零量 bar**（explore 窗 281 根，多为 OKX 停机打印的合成平盘 bar）：对成交额时钟贡献 0，自然被吸收进跨越它的桶；两条臂使用同一套缺失规则。

**对齐契约（整个 runner 的地基）**：`log_returns` 比 bar 数少一个，`returns[i]` 是**第 i+1 根 bar** 的收益，而 `bucket_edges` 发出的是 **bar 索引**。直接相配会让每个桶系统性错位一根。runner 因此丢弃首根 bar（`aligned = frame.iloc[1:]`）使两者逐位对应，并断言长度相等。

> **这条错位没有任何统计检验能发现**：零假设下收益与成交额本就无耦合，错位之后仍然无耦合，KS 均匀性检验照样通过。它只能靠契约本身来防。守护手段是 `_aggregate_returns` 对越界桶边界抛错、`paired_null_draws` 校验两数组等长、以及 runner 冒烟测试里的不变量断言 `bars_aligned == bars - 1`（已用变异测试验证：把对齐改回原 frame 会让 2 个测试变红）。

## 2. 时钟构造

尺度阶梯：**`{15m: 3, 1h: 12, 4h: 48, 12h: 144}`**（因子为 5m 根数）。

| 尺度 | factor | 日历根数 `N_s` |
|---|---|---|
| 15m | 3 | 154,751 |
| 1h | 12 | 38,687 |
| 4h | 48 | 9,671 |
| 12h | 144 | 3,223 |

**5m 尺度被排除，理由是数学退化而非结果偏好**：样本量匹配要求成交额桶数等于 bar 数，而每桶至少含一根 bar，于是每桶恰好一根——两个时钟的划分**逐位恒等**，`Δ_s ≡ 0`，零分布方差为零。已实测确认：factor=1 时 `edges == arange(1, n+1)`，与日历划分 bit-for-bit 相同；factor ∈ {2,3,12,48,144} 均不退化。此项在 PROTOCOL 冻结前发现并修正，不构成事后挑尺度。

**封桶规则**（无自由度）：

1. 桶在**累计成交额首次达到或超过 `V_s` 的那根 5m bar 结束时**封闭。不做 bar 内切分——5m 是采样下限。
2. **溢出不结转**。等价表述：每桶 = 「累计成交额 ≥ `V_s` 的最小 5m 连续块」。
3. 尾部不足 `V_s` 的残桶丢弃，不短装输出。

**样本量匹配**：因每桶均超额，朴素取 `V_s = 总额 / N_s` 会使桶数少于 `N_s`。对 `V_s` 二分搜索使 `M_s → N_s`，容差 `|M_s − N_s| ≤ max(1, 0.001 · N_s)`，上限 100 次迭代。二分下界取 `min(qv[qv>0])`（可证明的桶数上限，非魔数）；若该上界仍不足 `N_s` 则立即返回不收敛。

桶的 OHLCV 由成员 5m bar 聚合（`H`=max，`L`=min，`C`=末根 close，`V`/`QV`=sum），并记录**桶的日历时长 `Δt`**。

**保真度必须报告，不得隐藏**：5m 是采样下限，桶边界只能落在 5m 边界上。RESULTS 须给出每尺度的 `M_s`/`N_s`/`V_s`、桶实际成交额相对 `V_s` 的 p5/p50/p95、单根 5m 即成桶的占比。

## 3. 测度定义

统一定义：

- **收益**：`r_t = log(C_t / C_{t−1})`。选对数收益因为跨尺度可加，两条臂的聚合口径必须自洽。
- **δ**：`δ = (C − VWAP) / (H − L)`，`VWAP = quote_volume / volume`；`H = L` 或零成交量时 `δ = 0`。
- **方向命中率**：`r = 0` 与非有限值的样本对从统计中剔除并如实计数（平盘 bar 无方向信息）。

| 类别 | 测度 | 角色 |
|---|---|---|
| 非参数 | Spearman 秩自相关 ρ_S(lag 1) | **主判据** |
| 非参数 | 方向命中率 sign(r_t) → sign(r_{t+1}) | **主判据** |
| 非参数 | Spearman(δ_t, r_{t+1}) | **主判据** |
| 参数 | 方差比 VR(q)，q ∈ {2,4,8} | 佐证 |
| 参数 | OLS R²：r_{t+1} ~ δ_t | 佐证 |
| 参数 | 超额峰度 | **健全性检验** |

**主判据取非参数的理由**：DOGE 右尾极宽，二阶矩统计量会被极少数极端 bar 主导。这正是功效墙的技术根源——不是效应不存在，而是**度量本身被肥尾吃掉了功效**。

**参数与非参数背离时不判失败，而是写进结论**：背离说明信号存在但被尾部吞掉，这是可操作情报。

## 4. 零假设构造

主统计量 `Δ_s = 测度(D_s) − 测度(C_s)`，每尺度一个。

配对设计的功效来源：RFS 曾在日历时钟上扫 7 个频率、各自独立问「有没有 alpha」，Šidák 惩罚重、功效被稀释；本设计在每个尺度上做**同尺度对照**，看的是增量，共同的市场噪声在配对内被抵消。判据是符号一致性而非最大值，天然免疫「挑赢家」。

**两类主测度各配一个恰当的 null**：

| 主测度 | 零假设 | 构造 |
|---|---|---|
| 秩自相关、方向命中率 | 收益的时序结构与成交额划分无耦合 | 平稳 block bootstrap 重排 **5m 收益序列**，成交额序列**冻结** |
| δ 预测力 | δ 与未来收益无耦合 | 平稳 block bootstrap 重排**聚合后的 δ 序列**，收益与成交额**都不动** |

因成交额被冻结，桶划分在整个重采样循环里不变，`edges_by_scale` 只算一次并复用——这既是性能，也是 null 设计正确的体现：若某个 null 需要重新分桶，它就打断了不该打断的东西。

> 设计注记：曾考虑用单一 null（重排收益、冻结成交额）覆盖全部测度，但那会让 δ 在 null 下变成混合物——`C` 来自重排后的路径而 `H`/`L`/`VWAP` 仍来自原始数据。故分设两个 null。亦曾考虑对 δ 用 i.i.d. 置换，已否决：置换破坏 δ 自身的局部依赖，使零分布过窄，是假阳性的直接来源。

**参数（预注册，冻结）**：

- Bootstrap 次数 `B = 2000`，`seed = 0`
- **block 长度 = 12**（1 小时）。由预注册规则算出：5m 对数收益的 |ACF| 首次落入 ±2/√n 带的 lag，向上取整到 12 的倍数、下限 12。跑完后不得调整。

**零分布已被证明标定正确**（元测试，在已知无效应的合成数据上跑完整流水线，检查 p 值均匀性）：

| 元测试 | KS p |
|---|---|
| 收益 null（factors 3/12/48） | **0.8509** |
| δ null（block bootstrap，AR(0.9)） | **0.7793** |
| δ null 的 i.i.d. 反事实（**断言必须失败**） | **7.72e-09** |

第三行是关键：它证明第二行那条元测试**确有鉴别力**，能识别 block bootstrap 退化为 i.i.d. 置换。此前该断言仅是未经验证的假设——在 AR(0.5) 构造下实测 i.i.d. 版本 KS p = 0.0479，反而通过，30 个种子只有 10% 拒绝；提高到 AR(0.9)/block=60 后拒绝率 100%。

## 5. 闸门（预注册）

四尺度的配对差分用各自零分布标准差归一化后求和，合并统计量的零分布取自**同一批联合抽样**，跨尺度相关性因此自动进入零分布，不作任何独立性假设。经验 p 值为 `(extreme + 1) / (B + 1)`，加一确保 p 永不为 0。

- **G1 主检验**：三个主测度中任一的 `p_combined ≤ 0.016952`（Šidák 校正，3 个主测度，family α = 0.05）
- **G2 健全性**：峰度在 **≥ 3/4** 尺度上，成交额时钟低于日历时钟
- **G3 方向一致性**：过关测度的 `Δ_s` 在 **≥ 3/4** 尺度同号，防止单尺度极端值撑起合并 p

**G2 比较的是两条臂之间，不是聚合前后**——这个区别是实质性的。等长聚合在波动率聚集下**反而会提高**峰度，若按「聚合必降峰度」立判据，一个正确的实现会被误判。实测（GARCH(1,1)，成交额与瞬时波动率正相关，即 subordination 理论的标准前提）：

| factor | 日历峰度 | 成交额峰度 | `dollar < calendar` |
|---|---|---|---|
| 3 | 2.599 | 1.582 | PASS |
| 12 | 2.308 | 0.925 | PASS |
| 48 | 1.731 | 0.538 | PASS |

（5m 原始峰度 1.973；日历臂确实上升到 2.599，而成交额臂降到 1.582。）**G2 前提成立。**

### 裁决语义（三者互不相同，不得混淆）

| 裁决 | 含义 |
|---|---|
| **PASS** | 三门全过，可进入 S 阶段 |
| **CLOSED** | 研究方向关闭——这是一个**有效的研究结论** |
| **INVALID** | G2 失败 = **实现有 bug，整个诊断作废重做**，绝不是市场结论 |

把实现 bug 记成研究结论，是这套流程最需要防的事。
