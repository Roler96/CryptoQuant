# DOGE 现货 5m 下破回收协议（DLSR v1）

> 冻结日期：`2026-07-24`。状态：`FIT / 待执行`。
>
> 本文件只预注册假设、规则和未来 PASS/FAIL 条件，不包含研究结果。

## 研究问题

DOGE 现货在高成交量、大振幅的 5m bar 内跌破此前一小时低点，又在同一根闭合 bar
收回该低点并收在自身区间上部，可能代表一次短暂卖单/止损流耗尽；随后一小时是否存在
足以覆盖保守 taker 成本的向上回收？

这是一个可证伪的**失败拍卖几何**假设。“流动性扫单”只是 OHLCV 代理：本研究没有
订单簿、逐笔成交或强平标签，不能声称识别了真实止损、主动买卖方向或清算。

## 数据、边界与时序

- 市场仅为 OKX `DOGE-USDT` 现货；输入仅为交易所确认闭合的原生 `5m` OHLCV。
- 禁止从 `1h` 向上采样制造 5m bar；不读取 BTC、ETH、永续、funding、OI、盘口或社交数据。
  资金费口径为 `off`（现货不适用）。
- 探索窗硬编码为
  `2021-01-01 00:00:00 UTC <= bar_open_ts < 2025-06-01 00:00:00 UTC`。
  不使用探索起点以前的数据预热；最初的窗口只作探索窗内 warm-up。
- 只读覆盖核查已确认上述固定探索窗存在原生 DOGE 现货 5m 序列；该核查没有计算信号、
  收益或候选参数表现。
- bar `t` 的时间戳是其 open，覆盖 `[ts_t, ts_t + 300000ms)`；只有到
  `ts_t + 300000ms` 闭合后策略才可读取其 OHLCV。信号在 `t` 闭合时产生，只计划在时间戳
  恰为 `ts_t + 300000ms` 的连续下一根 bar `t+1` open 成交。
- 任一特征窗口内若时间戳不按 `300000ms` 连续、字段非有限或 OHLC 关系非法，则不补值、
  不缩短窗口，清空候选状态并重新累计完整 warm-up。
- 信号 bar 必须 `volume > 0`。若连续的 `t+1` 不存在或其 `volume <= 0`，该入场事件作废，
  不得把 pending order 顺延到更晚 open 追入。
- 探索窗末端只有能在 `< 2025-06-01` 内完成计划退出的 episode 才可纳入；不得为完成持仓
  读取冻结点后的 bar。
- 顺序验证只允许在 discovery 通过后的后续步骤中执行：
  `forward_holdout("doge-spot-5m-dlsr-v1", end="2027-06-01")`。提案阶段不读取该窗口，
  且禁止把固定终点替换为 `latest`、省略 `end` 或使用 `now()`。

诚实警示：`2025-06-01` 至 `2026-08-01` 的 DOGE 路径已被作废的旧研究纲领观察过，
只能算稳健性级证据；真正未被触碰的裁决段保守定义为
`2026-08-01 <= ts < 2027-06-01`，它只能随时间累积，不能催。

## 冻结特征

记闭合 bar `i` 的 OHLCV 为 `O_i, H_i, L_i, C_i, V_i`，其中 `V_i` 是 OKX base
volume。合法 bar 必须满足
`0 < L_i <= min(O_i, C_i) <= max(O_i, C_i) <= H_i` 且 `V_i >= 0`；
所有字段必须有限。

1. `range_i = log(H_i / L_i)`。
2. `floor_t = min(L_i, i=t-12..t-1)`：只取当前 bar 之前连续 12 根，即过去一小时低点。
3. 基线窗为严格早于 `t` 的连续 2,016 根 5m bar，即 `i=t-2016..t-1`：
   - `range_med_t = median(range_i)`；
   - `volume_med_t = median(V_i)`。
4. `sweep_depth_t = log(floor_t / L_t)`。
5. 当 `H_t > L_t` 时，
   `close_location_t = (C_t - L_t) / (H_t - L_t)`。

若 `range_med_t <= 0`、`volume_med_t <= 0`，或窗口内任一 bar 不合法，则 bar `t`
不能产生信号。当前 bar 永远不进入自己的 floor 或基线。

## 冻结主规则

### 冲击壳层

空仓且冷却完成时，bar `t` 必须先同时满足：

1. `L_t < floor_t`；
2. `sweep_depth_t >= 0.5 * range_med_t`；
3. `range_t >= 3.0 * range_med_t`；
4. `V_t >= 3.0 * volume_med_t`。

### 回收几何与入场

冲击壳层还必须同时满足：

5. `C_t > floor_t`，即闭合前已收回此前一小时低点；
6. `close_location_t >= 0.75`，即收在当前 bar 区间上四分之一内。

六项全部成立才接受一个事件。策略在连续下一根 `t+1` open 把目标从 `0` 改为 `0.25`；
只允许目标集合 `{0, 0.25}`，现货绝不产生负 target，不借币、不加杠杆、不叠加仓位。

### 持有、退出与冷却

- 主版从入场 bar 起固定持有 12 根完整 5m bar；第 12 根闭合后返回目标 `0`，在再下一根
  open 退出，计划持有时间为 60 分钟。
- 不使用 bar high/low 止盈、止损或 trailing；退出不依赖未知的 bar 内路径。
- 若计划退出 bar `volume <= 0`，目标持续为 `0`，在第一根连续且正成交量的后续 bar open
  退出；延迟期间逐 bar MTM、不得接受新事件，实际延迟完整计入该 episode。
- 若持仓期间出现缺失 bar，第一根恢复 bar open 强平、计完整成本并标记
  `DATA_GAP_EXIT`；包含该情况的研究运行不得判 PASS，因为真实时间路径不可重建。
- 实际退出后冷却 144 根完整 5m bar（12 小时）；持仓和冷却中的新壳层事件全部忽略，
  不延长持有或冷却。若入场因下一 bar 缺失/零量被拒，事件同样被消费并从计划入场时刻
  开始冷却，禁止追单。
- “日内”在本协议中由固定短持有定义，不按任意 UTC 日界切仓，也不使用已被探索过的
  UTC 时段统计。主版计划持有 60 分钟，冻结邻域最长 120 分钟。

这些状态转换要求执行层能反馈 fill/rejection/flat 状态；在该反馈能力完成并通过合成测试
前，不得以当前 pending 自动顺延语义代替本协议。

## 成交、费用与记账

- 主成本为每边 `15 bps`：`10 bps` fee + `5 bps` 不利 slippage。
- 压力成本为每边 `25 bps`：`10 bps` fee + `15 bps` 不利 slippage。
- 一笔现货 episode 包含一次买入和一次卖出，两次成交都计费；只按 taker 建模，不假设
  maker 返佣、排队成交或可在 K 线极值成交。
- Sizing 固定为 `Sizing.ON_ENTRY`：入场目标变化时以入场前权益和实际 open 一次定量，
  持有期币数不因价格变化重算；这不是 `REBALANCE`。
- 固定初始资金为 `10,000 USDT`；不复用重叠仓位。权益按每根真实 5m close 逐市，
  日收益从该权益路径取 UTC 日末值，MaxDD 使用完整 5m 真实时间路径。
- 数据末端仍有仓位时，在最后一根可用 bar close 施加额外一次不利滑点和手续费强平，
  明确标注；探索窗中这类 episode 不计为正常闭合样本。

## 冲击壳层随机入场零假设

从任意 5m 时点随机会把“极端行情”与“普通行情”混为机制证据，因此禁止。每个版本的
随机风险池固定为该版本的**冲击壳层**：满足下破深度、range、volume、连续 warm-up 和
可成交要求，但不施加 `C_t > floor_t` 或 `close_location_t >= 0.75`。

对每个版本生成 `10,000` 个有效随机计划，固定种子 `20260724`：

1. 与真实 accepted episodes 在“入场自然年 × UTC 六小时桶 × 实际持有 bar 数”中的数量
   完全相同；现货 funding 为 `off`，因此没有资金费安全窗这一额外匹配轴。
2. 从对应壳层中无放回抽样，使用相同 `0.25` 仓位、`15 bps/边`成本、零量/缺口规则、
   无重叠约束和 144-bar 冷却。
3. 违反持有或冷却约束的整组计划拒绝并重抽；不足 `10,000` 个有效计划即按功效不足判
   `DISCOVERY FAIL`，不得放宽匹配条件。
4. 统计量固定为按入场名义归一化的平均净 episode return。
5. 单侧
   `p_raw = (1 + count(random_stat >= observed_stat)) / (10000 + 1)`；
   对七次家族尝试作
   `p_sidak = 1 - (1 - p_raw)^7`。

这个零假设检验“同样的大振幅、高量、下破事件中，回收几何是否有增量”，而不是检验
DOGE 极端行情是否不同于普通行情。

## 发现门（探索窗 `< 2025-06-01`）

main 必须同时通过以下全部条件：

1. `15 bps/边`总收益 `> 0`；基于 UTC 日权益收益、零无风险利率和 `sqrt(365)` 年化的
   Sharpe `>= 0.75`；完整 5m 路径 MaxDD `<= 15%`。
2. `25 bps/边`压力总收益 `> 0`。
3. 从已冻结的 accepted-event 日程中抑制最佳净 PnL episode、且不让被其冷却挡住的事件
   补位后，重放总收益仍 `> 0`。
4. 至少 80 笔正常闭合 episode，且 2021、2022、2023、2024 每个完整自然年至少 10 笔。
5. 2021–2024 四个冷启动自然年中至少三个在 `15 bps/边`后收益为正。每年以现金和固定
   初资开始，可用该年以前但仍位于探索窗内的 bar 作 warm-up，不继承仓位或权益。
   `2025-01-01..2025-06-01` 进入总体路径，但不冒充完整自然年。
6. 对包含零事件日的 UTC 日权益收益做长度 28 日的 circular moving-block bootstrap：
   `10,000` 次、种子 `20260724`，复合总收益的 `P5 > 0`。
7. 冲击壳层随机入场检验的七次 Šidák 校正后单侧 `p_sidak <= 0.10`。
8. 七个冻结版本中至少五个在 `15 bps/边`后总收益为正；这只检查参数稳定性，仍不得用
   邻域替代 main。
9. 不存在陈旧 pending 顺延成交、负现货 target、未标记的数据缺口退出或未计成本的末尾
   仓位。

任一条件失败即 `DISCOVERY FAIL`，不得依据后续年份修改参数。

## 顺序验证门（后续步骤执行）

只在 discovery 全部通过且时间到达固定终点后执行一次；
不作中途窥视。读取任何 holdout bar 前必须依次完成：

1. `plan = forward_holdout("doge-spot-5m-dlsr-v1", end="2027-06-01")`；
2. 在查询前调用
   `record_holdout_access(study="doge-spot-5m-dlsr-v1", segment="forward",
   hypothesis="冻结 DLSR main 的回收几何在主/压力成本、去最佳 episode、冲击壳层随机基准及未触碰段上同时过门",
   fingerprint=plan.fingerprint)`；
3. 一次性读取 `[2025-06-01, 2027-06-01)`；只运行 main，不打开邻域。

同一次固定访问内分别报告：

- 稳健性级段：`2025-06-01 <= ts < 2026-08-01`；
- 保守未触碰裁决段：`2026-08-01 <= ts < 2027-06-01`。

全 forward、稳健性段和未触碰段分别以现金和固定初资冷启动，不继承跨边界仓位或权益；
可用各自起点以前、已在这次合规读取中的 bar 只作因果 warm-up。三份报告互不拿结果调参。

两段都必须各自满足：

1. `15 bps/边`和 `25 bps/边`总收益均 `> 0`；
2. 抑制最佳 episode、且不补入被挡事件后收益仍 `> 0`；
3. 完整 5m 路径 MaxDD `<= 15%`；
4. 至少 20 笔正常闭合 episode；
5. 同一冲击壳层随机检验的单侧 `p_raw <= 0.20`。

此外，全 forward 路径的 UTC 日收益 Sharpe 必须 `>= 0.50`；保守未触碰段还必须：

- 28 日 circular moving-block bootstrap 的复合总收益 `P5 > 0`；
- `2026-08-01..2026-11-01`、`2026-11-01..2027-02-01`、
  `2027-02-01..2027-05-01` 三个固定三月块中至少两个在主成本后为正；最后一个月至
  `2027-06-01` 仍进入该段总体路径。

任一结果门失败即 `VALIDATION FAIL`。到固定终点仍未达到最小 episode 数则为
`INCONCLUSIVE`，不能 PASS、不能批资金，也不能悄悄把同一 v1 的终点延到 `latest`；
若要继续积累，必须在读取前另立固定终点协议，并把新增访问计入多重检验。

## 预期失败模式

- 回收可能在信号 bar 内已经完成，close 到下一 open 的 gap 会吃掉剩余幅度。
- 5m last-trade OHLCV 可能把陈旧成交或单笔异常误当成可交易的下破与回收。
- 成交量不区分主动方向；“扫止损/卖方耗尽”的经济叙述可能不成立。
- 一次 60 分钟现货持仓的幅度可能无法覆盖 30/50 bps 往返成本。
- 事件可能集中在少数危机周或单一制度，导致随机壳层、年度迁移或 28 日 block
  bootstrap 失败。
- 2,016-bar 基线、过去一小时 floor 和 OHLC 几何可能只是脆弱的技术形态，而非结构性
  流动性补偿。
- K 线没有 bid/ask、盘口深度、部分成交、延迟或容量；即使未来过门也只能先进入真实
  盘口 shadow，不直接批准实盘资金。
- 零量退出、数据缺口和当前引擎的 pending/fill-feedback 差异可能破坏固定持有语义。

## 工程前置条件

仓储与抓取层支持 `(DOGE-USDT, 5m)`，但当前通用历史 loader 仍以 `1h` 为基础，不能向下
resample。后续 backtester 必须直接读取原生 5m 构造 `Series`，或先补通用 loader/CLI；
任何从 1h 制造 5m 的实现均使研究作废。

当前 `Context` 也不提供完整 fill/rejection/flat 反馈，默认 pending 可能跨零量 bar 或缺口
顺延。实现阶段必须先补足或在执行适配层显式封死本协议的“拒绝即作废、缺口不追单、
实际退出后冷却”状态，并用合成 bar 覆盖这些路径。完成这些工程工作仍只得到
工程就绪状态，不构成研究结果。
