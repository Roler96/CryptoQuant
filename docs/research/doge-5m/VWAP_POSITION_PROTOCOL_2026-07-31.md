## 1. 为什么要做这一轮

上一轮设计（`2026-07-30-doge-dollar-clock-design.md` §2.2）声称 `δ = (C − VWAP)/(H − L)` 是一个与历史研究近乎正交的新维度，依据是实测 `corr(VWAP位置, close位置) = 0.1415`。

D4 第 4 项复核推翻了它：实际喂进流水线的 δ 与 close 位置相关 **0.94**。原因是 `δ = close位置 − VWAP位置` 而 VWAP 位置的变异只有 close 位置的 38%，δ 被后者主导。

**真正正交的量是 `VWAP 位置` 本身，它从未被检验过。** 本轮就检验它。

定义：

```
v_t = (VWAP_t − L_t) / (H_t − L_t)，  VWAP_t = quote_volume_t / volume_t
c_t = (C_t − L_t) / (H_t − L_t)                    ← 历史研究反复用过的那一维
```

`H = L` 或零成交量时 `v` 与 `c` 均无定义，该 bar 从统计中剔除并报告剔除比例。

机制读法：`c` 只看 bar 的最后一个 tick（样本量为 1 的估计）；`v` 是整根 bar 内成交量加权的价格重心。`v` 高意味着成交集中在区间上部。

## 2. 假说与它的方向性

**主假说**：`v_t` 对 `r_{t+1}` 携带**独立于 `c_t`** 的秩预测力。

**本假说不预设方向。** 因此主检验是双侧的，方向约束由跨尺度与跨时钟的符号一致性提供（G2、G3）。

> 这一条是对上一轮教训的直接处理。上一轮的闸门 G1 双侧、G3 只查符号，而假说本身**是有方向的**（"成交额时钟应当揭示可预测性"），于是闸门放行了一个与假说矛盾的结果。本轮假说无方向，双侧检验因此是恰当的而非疏漏。

## 3. 检验设计

### 3.1 主统计量

在每个尺度、每个时钟上：

```
M = 秩偏相关( v_t , r_{t+1} | c_t )
```

控制 `c_t` 是必须的，且是本轮的核心：要的是 `v` 在 `c` 之外的**增量**。不得因为 `corr(v, c) = 0.137` 已经很低就省略这一步——那正是上一轮"用一个量的性质论证另一个量"的错误形状。

### 3.2 两个时钟的分工，以及判别规则

主判据在**成交额时钟**上，日历时钟作为**判别对照**。

依据是上一轮的机制发现：日历时钟的表观预测力主要是买卖价差反弹（lag-1 尖峰），成交额时钟能把它洗掉。因此两条臂的对照可以充当**信号真伪的判别器**——这是上一轮产出的可复用工具在本轮的第一次应用。

**预注册判别表**：

| 成交额时钟 | 日历时钟 | 判读 |
|---|---|---|
| 显著 | 显著且同号 | **真实信号** |
| 不显著 | 显著 | **价差反弹伪影** |
| 显著 | 不显著或反号 | **存疑**——可能是成交额时钟自身引入的伪影，不得直接采信 |
| 不显著 | 不显著 | 无信号 |

### 3.3 零假设

平稳 block bootstrap 重排 `v` 序列，`r` 与 `c` **都不动**。只打断待检验的那一条耦合。

`B = 2000`，`seed = 0`，block 长度 **12**（沿用上一轮由预注册规则算出并冻结的值）。

**必须披露的 null 不对称**：重排 `v` 时同时打断了 `v ↔ r_{t+1}` 与 `v ↔ c_t`。于是零分布中的 `v` 不会被残差化削弱，而观测的 `v` 会（`corr(v,c) = 0.137`，虽弱但非零）。检验因此**偏保守**——显著结果比表面更强，不显著**不能**读作无效应的证明。此处 `corr(v,c)` 远低于上一轮 Δt 的情形，故不对称程度较轻。

### 3.4 尺度

沿用 `{15m: 3, 1h: 12, 4h: 48, 12h: 144}`。5m 仍排除（样本量匹配下两个时钟逐位恒等，Δ 恒为 0）。

## 5. 闸门（预注册）

四尺度的偏相关用各自零分布标准差归一化后求和，合并统计量的零分布取自同一批联合抽样。经验 p 值为 `(extreme+1)/(B+1)`。

- **G1 显著性**：成交额时钟上合并 `p ≤ 0.05`（单一主检验，无需 Šidák 校正）
- **G2 符号一致**：`M` 在 **≥3/4** 尺度同号
- **G3 判别**：日历时钟上的 `M` 与成交额时钟同号（排除成交额时钟自身伪影）
- **G4 效应量 —— 本轮新增，且是关键**：`|M|` 必须在 **≥2/4** 尺度上达到该尺度的**可交易下限**

### G4 的门槛，及其依据

统计显著不等于有用。15m 尺度有 15 万个观测，`|ρ| = 0.005` 都能显著。本仓库历史上反复出现"毛 edge 真实但净收益为负"，根因就是从未在看结果之前把成本墙画成一条线。

可交易下限 = 每期往返成本 ÷ 该尺度收益标准差，即"信号带来的期望收益刚好抵消一次往返成本"所需的相关系数：

| 尺度 | σ_r | 每期往返成本 | **可交易 \|IC\| 下限** |
|---|---|---|---|
| 15m | 78.3 bps | 3.39 bps | **0.0433** |
| 1h | 149.2 bps | 3.39 bps | **0.0228** |
| 4h | 296.5 bps | 3.39 bps | **0.0114** |
| 12h | 510.3 bps | 3.39 bps | **0.0067** |

成本取 Corwin–Schultz 估计的 5m 中位有效价差 3.39 bps（`DOLLAR_CLOCK_RESULTS_2026-07-30.md` §4.1）。

**这是最宽松的下限**：假定满仓、线性、无市场冲击、无滑点、每期只换手一次，且成本不随尺度放大。真实成本只会更高，因此**达不到这条线的信号一定不可交易**，达到了也只是必要而非充分。

注意成本墙在粗尺度上显著更低（12h 的 0.0067 vs 15m 的 0.0433），因为 σ_r 随尺度增长快于成本。这本身解释了本仓库日内高频反转家族的系统性失败。

## 6. 裁决语义

| 裁决 | 条件 | 含义 |
|---|---|---|
| **TRADEABLE-LEAD** | G1+G2+G3+G4 全过 | 信号真实且超过成本墙，值得进入策略构造 |
| **REAL-BUT-SUBTHRESHOLD** | G1+G2+G3 过，G4 不过 | 信号真实但低于成本墙。**方向关闭**，且这是一个有效结论 |
| **ARTEFACT** | G1+G2 过，G3 不过 | 疑似成交额时钟伪影，不得采信 |
| **CLOSED** | G1 或 G2 不过 | 无信号 |
| **INVALID** | 数据指纹不符或健全性检验失败 | 实现有问题，作废重做 |

**先验预期（写在此处以便事后对照）**：最可能的结果是 **REAL-BUT-SUBTHRESHOLD**。上一轮实测的所有真实信号量级都在 `|ρ| ≈ 0.01–0.03`，而 15m/1h 的门槛是 0.043/0.023。若 `v` 与它们同量级，则只有 4h/12h 有机会过线。

记录这个先验不是为了自我实现，而是为了让事后的意外可被识别——若结果大幅偏离，应当先怀疑实现而非庆祝发现。

## 7. 健全性检验（失败即 INVALID）

1. **`c` 的价差反弹签名**：`c` 本身对 `r_{t+1}` 的预测力，在**日历时钟上的绝对值大于成交额时钟**，且需在 **≥3/4 尺度**上成立。这是**量级比较，不是统计检验**（重现上一轮 §3.2 的机制）。若不成立，说明流水线与上一轮不一致
2. **`corr(v, c)` 复现**：日历 5m 上应为 `0.137 ± 0.02`，与 D4 第 4 项独立记录的 `+0.1374` 一致
3. **数据指纹**：`12b8ca59c15fc519`

**两种 INVALID 的失败形态不同，刻意如此**：

- **指纹不符 → 立即中止**，不产出任何 JSON。此时连数据都不是预注册的那一份，跑下去毫无意义
- **§7.1 / §7.2 失败 → 跑完并产出 JSON，`verdict` 标记为 `INVALID`**。此时数据正确但流水线可疑，留下完整数字有助于排查

## 7bis. 协议澄清（2026-07-31，**在跑任何检验之前**）

实现完成后的代码审查指出本协议有四处歧义，实现者不得不自行外推。现予以写死。

**这次修订是合法的预注册行为**，因为它发生在**跑研究之前**——预注册要防的是"看到结果后挑选规则"。为杜绝结果导向的嫌疑，下述每一条采纳的都是**实现者在完全不知道结果的情况下已经固化的口径**，而非我重新挑选：

| 原歧义 | 现写死为 | 出处 |
|---|---|---|
| §7.2 "约为 0.137" 无容差 | `±0.02`（相对约 15%） | 已并入 §7 第 2 条 |
| §7.1 未定义在几个尺度上成立、"显著"何指 | ≥3/4 尺度，量级比较非统计检验 | 已并入 §7 第 1 条 |
| §3.2 判别表的"显著/不显著"口径未定义 | **合并统计量**的 p 值（与 G1 同口径） | 见下 |
| INVALID 的失败形态未统一 | 指纹不符中止；健全性失败留痕 | 已并入 §7 |

**关于 §3.2 与 G3 粒度不同的说明**（审查指出此处易混淆）：两者查的**不是同一件事**，因此粒度不同是设计使然而非疏漏——

- **§3.2 判别表**查的是**显著性**（信号在这个时钟上存不存在），故用**合并统计量的 p 值**，与 G1 一致
- **G3 闸门**查的是**符号**（两个时钟的方向是否一致），故用**逐尺度符号计数 ≥3/4**，与 G2 一致

审查同时指出实现者的报告漏披露了 §7.1 的聚合规则这一项自主判断。本节即为该项的补充披露。
