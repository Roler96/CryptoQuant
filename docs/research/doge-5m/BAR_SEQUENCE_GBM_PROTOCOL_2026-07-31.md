# 逐 bar 涨跌序列 → 非线性模型 — 预注册协议

- 日期：2026-07-31
- 研究标签：`doge-bar-sequence-gbm-v1`
- 承接：用户对既往 DOGE 研究纲领的两点批评——(1) 统计闸门/协议本身过严，可能把偏弱但真实
  的信号一并否掉；(2) 过去测的全是常见技术指标（动量/反转/VWAP位置/成交额时钟），指标本
  身太朴素。本轮针对这两点分别设计对策，见 §0。
- 标的：`DOGE-USDT` 现货 5m，**只用这一路数据**（现货，非永续；训练范围仅限 DOGE 自身历史，
  不并入其余 11 币种池化训练——用户已明确排除跨币池化）

**本文件在跑任何检验之前写成并提交。** 全部阈值、判别规则、效应量门槛均为预注册，跑完不得
调整。

## 0. 本轮对两点批评的具体回应

**"闸门太严"** → 不再用单一冻结切分 + 全局 Šidák 校正的二元 pass/fail，改用 5 折
expanding-window walk-forward，每折独立报告样本外表现，用"跨折稳定性"代替"单次通过阈值"；
仍然保留统计纪律（零假设、Šidák 家族校正、预注册），但纪律作用的对象从"一次性判死刑"变成
"多折一致性"。

**"指标太老套"** → 不再由研究者预先假设一个具体的手工关系（例如"上一根 bar 涨→下一根跌"），
而是把最原始的逐 bar 涨跌序列（符号 + 幅度）整段喂给一个可以刻画非线性/多阶交互的模型
（梯度提升树），让模型自己找结构。同时用线性基线做对照，直接检验"更大的模型"这个前提本身
是否成立——如果模型只学到了单一 lag 的线性关系，那就是在说"其实就是老指标"，本协议专门为
这个可能性留了一个裁决类别（§6 的 `LINEAR-ONLY`）。

## 1. 数据契约

- Explore 窗口：`[2021-01-01, 2025-06-01)`，**validate 窗口 `2025-06-01→2027-06-01` 不碰**
  （沿用 `FORWARD_FREEZE=2025-06-01` 的既定语义，见项目 memory `research-reset-2026-07-23`）
- 原始根数：**464,256**（`DOGE-USDT` 现货 5m，`ts < 2025-06-01T00:00:00Z`，**过滤退化 bar 之前**）
- 数据指纹：**在任何过滤之前**，对原始 464,256 根 bar 的 `(ts, open, high, low, close)` 按 `ts`
  升序逐行 `struct.pack('<qdddd', ...)` 后 sha256，取前 16 位十六进制，冻结为
  **`85cc617af4d57689`**。不符即作废重来，不得继续跑——**指纹校验必须先于退化 bar 过滤执行**，
  它验证的是"拉到的原始数据没变"，与过滤逻辑本身是否正确是两件事，不得合并成一步（合并了就
  没法区分"数据源变了"和"过滤代码写错了"这两种失败）。
- **退化 bar 过滤**（指纹校验通过之后执行）：剔除 `high<=low` 或 `volume<=0` 的 bar（OKX 停
  机期间打印的合成平盘 bar，见 memory `okx-outage-zero-volume-bars`）。**实测剔除 520 根**
  （占比 0.1120%），冻结为本轮基线；若某次重跑剔除数偏离这个基线，标记可疑并人工复核
  （§7.4）。过滤后剩余 **463,736** 根可用 bar，按 `ts` 重新连续编号——两根可用 bar 之间可能因
  中间的停机 bar 被剔除而存在真实的时间跳跃，这是刻意的（跳过停机期间等于承认那段时间没有
  真实收益发生，而不是把大量恒为零的人工收益点混进信号里）。

  > **2026-07-31 重新冻结说明**：本文件最初冻结的原始根数是 464,160（指纹
  > `3122d7bd0c97aeda`）。实现阶段（Task 3）发现当前 `data/cq.db` 里同一窗口是
  > 464,256 根——多出的 96 根均为正常 bar（退化 bar 剔除数仍是 520，未变），时间戳判断
  > 是并发 OHLCV 回填在协议冻结之后又补齐了一段历史缺口（见 memory
  > `ohlcv-concurrent-backfill-2026-07-23`）。经确认后按当前数据重新冻结上述数字，本节
  > 及下方 §1 对齐契约、§6 G4 推导中的根数均已更新；`σ_r`（46.68 bps）与 G4 门槛
  > （0.0726）在新根数下重新算出仍与旧值一致，未发生实质变化。

### 对齐契约

设**退化 bar 过滤之后**、按 `ts` 升序重新连续编号的收盘价为 `close_0, ..., close_{T-1}`
（`T = 463736`，即 §1 过滤后的可用根数，不是过滤前的 464,256）。

```
r_i = log(close_i / close_{i-1})   for i = 1..T-1        # r 的长度 T-1
```

在"决策时刻" `i`（即第 `i` 根 bar 收盘的瞬间，`i` 从 `N` 到 `T-2`）：

```
特征窗口 = { r_{i-N+1}, ..., r_i }     # 已实现，决策时刻可得
标签      = r_{i+1}                    # 下一根 bar 的收益，决策时刻不可得
```

`label 索引 = feature 索引 + 1`，这个关系必须有断言强制检查（呼应
`doge-5m-static-pipeline-pitfalls` 里 off-by-one 错位"没有任何统计检验能发现它"的教训）。

## 2. 假说与它的方向性

**主假说**：过去 `N` 根 bar 的涨跌序列（符号/幅度）整体上对 `r_{t+1}` 携带秩预测力，且这份
预测力**不能完全由单一 lag 的线性关系解释**（否则等价于旧指标）。

本假说不预设方向，也不预设是哪一个 lag 起作用——这正是与过去研究的方法论差异所在。

---

## 3. 特征与标签构造

三套特征集**并行跑、并行报告**，不得跑完后只挑表现最好的那个报告（那是资源禁止的"事后选
择"）：

| 特征集 | 定义 |
|---|---|
| `F_sign` | `s_j = sign(r_j) ∈ {-1, 0, +1}`，`j = i-N+1..i` |
| `F_ret`  | `z_j = (r_j - μ_train) / σ_train`，`μ_train`/`σ_train` 仅用该折**训练窗**内的 `r` 计算，不得用测试窗或全局统计量（避免跨折信息泄漏） |
| `F_both` | `F_sign` 与 `F_ret` 拼接 |

标签：

- 分类目标 `y = 1{r_{i+1} > 0}`（用于拟合）
- 评估用的连续量：`r_{i+1}` 本身（用于计算秩相关，见 §5.1）

## 4. 模型

- **线性基线**：`sklearn.linear_model.LogisticRegression`（L2 正则），正则强度
  `C ∈ {0.01, 0.1, 1.0}` 网格选择
- **候选模型**：`sklearn.ensemble.HistGradientBoostingClassifier`，`max_depth ∈ {2,3,4}`，
  `min_samples_leaf ∈ {500, 1000}`，`learning_rate = 0.05`（固定，不纳入网格），
  `max_iter` 上限 500、`n_iter_no_change=30` 早停

  选 `scikit-learn` 而非 LightGBM/XGBoost：本仓库目前没有任何 ML 依赖
  （`pyproject.toml` 只有 ccxt/numpy/pandas/scipy/loguru/pyyaml/dotenv/pydantic），
  `scikit-learn` 一个新依赖就能同时提供线性基线和梯度提升树两个模型，不必引入两个新包。
  这是本轮唯一的新增依赖，需要写进 `pyproject.toml`。
- `N ∈ {10, 20, 40}`，两个模型在同一折、同一特征集内共享同一个入选的 `N`（保证线性 vs
  GBM 的对照是同特征下的对照，不是选了不同输入的两个模型比较）

**超参选择**：每折训练窗内部按时间顺序切出最后 15% 作内部验证集，网格内选择使内部验证集
秩-IC（定义见 §5.1）最高的组合；外层测试折的表现不参与任何超参选择。

## 5. 验证协议：5 折 expanding-window walk-forward

日历锚定的折边界（预注册，不得跑完后调整）：

| 折 | 训练窗 | 测试窗 |
|---|---|---|
| 1 | `[2021-01-01, 2022-06-30)` | `[2022-07-01, 2023-02-01)` |
| 2 | `[2021-01-01, 2023-01-31)` | `[2023-02-01, 2023-09-01)` |
| 3 | `[2021-01-01, 2023-08-31)` | `[2023-09-01, 2024-04-01)` |
| 4 | `[2021-01-01, 2024-03-31)` | `[2024-04-01, 2024-11-01)` |
| 5 | `[2021-01-01, 2024-10-31)` | `[2024-11-01, 2025-06-01)` |

区间一律左闭右开。训练窗结束日期与测试窗开始日期之间天然留出的 1 天（例如折 1 的
`2022-06-30`）**就是 embargo**，不是另外再扣一天——写成表格是为了让边界可核对，不是留白等
实现者自己推。

**Embargo**：每折训练窗末尾剔除测试窗开始前 1 个自然日（288 根 5m bar）的数据——这个余量
远大于 `N_max=40` 的特征回看长度 + 1 根标签前瞻所需的最小安全间隔（41 根 bar），刻意取整、
留足冗余而不是卡着最小值算。任何训练样本的标签索引落在 `[测试窗开始-embargo, 测试窗结束)`
内，必须被剔除并有断言强制检查。

### 5.1 主统计量

每折、每特征集：

```
IC_k = Spearman秩相关( 模型对测试折每个决策点输出的分数 , r_{i+1} 实际值 )
```

GBM 与逻辑回归的"分数"均取其预测的"上涨概率" `p̂`。

### 5.2 零假设与检验

对 5 折 `IC_k` 取中位数 `M = median(IC_1..IC_5)` 作为该特征集的检验统计量。

零分布：对每一折独立做**平稳 block bootstrap**，只重排该折**测试窗**内的标签序列
`r_{i+1}`（特征序列不动，只打断待检验的耦合），block 长度 `L_k = round(T_test,k^(1/3))`
（标准 stationary-bootstrap 启发式，逐折按其实际测试样本量计算，不得跨折套用同一个手工数
字）。`B = 2000`，`seed = 0`。每次重抽样后重新计算 5 折的 `median(IC)`，得到零分布，经验 p
值为 `(extreme+1)/(B+1)`。

**家族校正**：3 个特征集（`F_sign`/`F_ret`/`F_both`）算作一个假说家族，用 Šidák 校正，
family-wise `α=0.05` 对应单个检验阈值 `α' = 1-(1-0.05)^(1/3) ≈ 0.0170`。

## 6. 闸门与裁决（预注册）

四类闸门，每个特征集独立评估：

- **G1 存在性**：`p ≤ 0.0170`（Šidák 校正后，见 §5.2）
- **G2 符号一致**：5 折中 `IC_k` 同号 `≥ 4/5`
- **G3 非线性是否值回复杂度**：GBM 的 `IC_k` 在 `≥ 4/5` 折上不劣于同折线性基线的 `IC_k`
- **G4 成本墙**（关键，回应本仓库"统计显著≠可交易"的历史教训）：`median(|IC_1..IC_5|) ≥
  0.0726`

### G4 门槛的推导

`DOGE-USDT` 现货 5m explore 窗口、**过滤退化 bar 之后**实测 `σ_r = 46.68 bps`（log return 标
准差，`n=463,735`，与 §1 对齐契约的 `T=463736` 一致；按重新冻结后的根数复算，与旧值一致，
未变）。单边成本沿用此前 Corwin–Schultz 估计
的 5m 中位有效价差 `3.39 bps`（`DOLLAR_CLOCK_RESULTS_2026-07-30.md` §4.1，同一标的同一颗粒
度，直接复用不重新估计）。

```
可交易 |IC| 下限 = 3.39 / 46.68 ≈ 0.0726
```

这是最宽松的下限（满仓、线性、无滑点、每期一次换手），比历史上 15m/1h/4h/12h 的门槛
（0.0433/0.0228/0.0114/0.0067）都更严——细尺度的成本墙天然更高，这是本仓库反复验证过的结
构性事实，不是本轮新增假设。

### 裁决语义

| 裁决 | 条件 | 含义 |
|---|---|---|
| **TRADEABLE-LEAD** | G1+G2+G3+G4 全过 | 信号真实、模型的非线性确有增量、且过成本墙 |
| **REAL-BUT-SUBTHRESHOLD** | G1+G2+G3 过，G4 不过 | 信号真实但低于成本墙，方向关闭 |
| **LINEAR-ONLY** | G1+G2+G4 过，G3 不过 | 信号真实且过成本墙，但"更大的模型"没有增量——等价于旧的单一手工指标就够了，直接证伪本轮"指标太老套"这一假设的解法 |
| **CLOSED** | G1 或 G2 不过 | 无信号 |
| **INVALID** | 数据指纹不符，或防漏检（§7）任一失败 | 实现有问题，作废重做 |

**先验预期**（写在此处以便事后对照，不是为了自我实现）：最可能的结果是 `F_sign` 与
`F_ret` 分别落在 `CLOSED` 或 `REAL-BUT-SUBTHRESHOLD`——本仓库历史上 DOGE 单资产方向性研
究（1h 反转三条、bar 内 VWAP 位置）均无法穿透成本墙或与随机不可分。若本轮出现
`TRADEABLE-LEAD` 或哪怕是 `LINEAR-ONLY`，都值得先怀疑实现而非庆祝发现。

## 7. 防漏检与健全性检验（失败即 INVALID）

1. **Shuffle-label 对照**：在每折训练窗内，把训练标签随机打乱后重新训练同一模型，用真实
   测试折标签评估。打乱训练版本的 `median(IC)` 必须落在零分布的 95% 区间内（不显著）。若
   打乱标签训练出的模型在真实测试折上仍表现出显著 IC，说明特征构造存在信息泄漏，全部作废
   重查。
2. **Embargo 断言**：自动化检查每折训练集中不存在标签索引落入 `[测试窗开始-embargo, 测
   试窗结束)` 的样本，而不是人工检查一遍了事。
3. **特征/标签对齐单测**：构造一个收益率单调递增的合成序列，验证 `label 索引 = feature
   索引 + 1` 且模型能在此退化例子上学到解析已知的方向（回归测试，而不是只跑真实数据看结
   果合不合理）。
4. **停机零量 bar 剔除比例**：报告数字，若剔除比例明显偏离历史同期水平（可能意味着数据源
   出了新问题），标记为可疑并人工复核。
