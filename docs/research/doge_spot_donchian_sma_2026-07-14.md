# DOGE 现货 Donchian+SMA 门控趋势策略研究（2026-07-14）

## 结论先行

在防过拟合协议下，发现一个在 Train/Val/Test 三分段全部为正的现货做多策略族：
**日线 SMA 门控 + 4h Donchian 突破做多**。选定冻结配置 `SMA(30) e=45 x=30`，
进入测试网候选阶段。

该策略的核心逻辑：日线 SMA 判断大趋势方向，仅在价格站上 SMA 时允许做多；
4h Donchian 通道突破作为精确入场触发；价格回落跌破短期通道退出。
现货不能做空，但 SMA 门控在熊市中让策略保持空仓，起到"伪空头"保护作用。

## 一、数据

- 产品：OKX `DOGE/USDT` 现货 1h K 线，聚合为 4h 和 1d 使用
- 区间：2021-01-01 → 2026-07-12，48,456 根 1h bar
- 质量：无缺失、无重复、无 NaN
- 行情特征：年化波动率 ~130%，极端牛熊周期
  - 2021 +3526%、2022 -59%、2023 +28%、2024 +252%、2025 -63%、2026截至7月 -38%
- 数据存储：本地 `data/cryptoquant.db` 表 `ohlcv_okx_DOGE_USDT_1h`

- 成本压力：0 / 6 / 12 / 25 / 50 bps/边

### 通过标准

## 三、逐族结果

### 被否决的族

| 族 | 否决原因 |
|---|---|
| SMA 交叉做多 | Train/Val 正、Test 全负（-21% ~ -44%），与买入持有同向跌 |
| TSMOM 做多 | Train/Val 正、Test 全负（-14% ~ -17%），牛市 beta 撑不过熊市 |
| Donchian 做多（无门控） | 多数 Test 负；e=240 x=24 Test +15.5% 但邻域不稳 |
| RSI 超卖反弹 | 全线三段负或仅 Train 正；DOGE 超卖后继续跌 |
| 回撤反弹 | 信号过密（万级），Test 与 BH 同跌；抄底不可行 |
| 波动率目标 TSMOM | 全线巨额亏损（-97% ~ -98%），vol scaling 在 DOGE 上失效 |

### 存活族：日线 SMA 门控 + 4h Donchian 做多

日线 SMA 判断趋势方向：`close_daily > SMA(N)` 时为 bull regime。
4h Donchian 通道突破入场：`close_4h > rolling_high(entry_bars).shift(1)`。
退出：`close_4h < rolling_low(exit_bars).shift(1)` 或 regime 转熊。

90 个配置中 **76 个三分段全部为正**，参数平原极宽。

## 四、冻结配置：SMA(30) e=45 x=30

选定理由：
- 三分段 Sharpe 均在 2.3+ 以上，无短板
- Train DD -57.8%、Val DD -31.5%、Test DD -23.7%，回撤可控
- 56 笔交易，频率适中（~11 笔/年）
- 参数位于平原中心，邻域 SMA25-30 / e=30-60 / x=10-30 全正
- Test 收益 +61.0%，同期买入持有 -56.0%

## 五、策略规格

- **名称**：DogeSpotDonchianSma
- **产品**：OKX DOGE/USDT 现货
- **周期**：4h K 线（信号生成），日线 SMA（趋势门控）
- **方向**：仅做多
- **入场**：日线 close > SMA(30) 且 4h close > 4h rolling high(45).shift(1)
- **退出**：4h close < 4h rolling low(30).shift(1) 或日线 close < SMA(30)
- **成本**：12 bps/边（10 bps 手续费 + 2 bps 滑点）
- **信号类型**：持仓型（signal_is_position = True）
- **版本**：1.0.0

## 六、注意事项与上线门槛

1. **该族在本仓库此前研究中已接触过全样本**：邻域扫描中使用了完整 2021-2026
   数据，本表不构成完全独立的 OOS 证明。真正的 OOS 只能来自测试网/实盘的新样本。
2. **Train 段收益极高**（+906%）主要来自 2021 疯牛，不应作为未来期望值。
   Test 段 +61% / Sharpe 1.44 是更现实的参考。
3. **现货无空头保护**：SMA 门控在熊市中 flat，但若 DOGE 在 SMA 上方突然暴跌
  （如 2021-12-14 单日 +150% 反弹后的快速回落），4h Donchian 退出可能滞后。
   live 部署应加百分比止损。
4. **上线门槛**：
   - 先用 demo/testnet 连续运行，至少完成 20 次开平仓
   - 逐单核对成交价与"下一根 4h 开盘 ± 滑点假设"偏差不超过 25 bps
   - 连续 20 笔独立交易后，若净收益不为正或 PF ≤ 1，则停用
   - 真仓先以 100 USDT 名义限额灰度，至少一个月后再评估
5. 不得基于本文数字继续调参后仍宣称三分段验证有效；任何参数改动都开启新的
   研究版本并重新走协议。
