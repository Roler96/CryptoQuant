# DOGE 自身数据年度研究协议

## 固定时间结构

后续所有新DOGE现货策略使用统一时间协议：

| 区间 | 角色 | 允许行为 |
|---|---|---|
| 2021-01-01 .. 2024-01-01 | Discovery | 提出机制、初始参数和失败反证 |
| 2024-01-01 .. 2025-01-01 | Validation | 比较有限候选；不得增加新自由度 |
| 2025-01-01 .. 2026-01-01 | Pre-freeze audit | 冻结最终规则后只读取一次 |
| 2026-01-01 .. latest | Temporal holdout | 最终规则一次性裁决，不允许调参 |

2026年只作为时间冻结样本，不参与策略发现、参数选择、阈值选择、消融选择或退出规则选择。

## 数据边界

- 主策略输入只允许OKX `DOGE-USDT`现货OHLCV。
- 不使用BTC、ETH、跨币市场广度或相关性。
- DOGE swap、funding、OI若以后启用，必须作为单独研究版本，并受其实际历史覆盖限制；不得把短历史forward-fill到早期年份。
- 所有bar必须闭合；不填补缺失bar；零成交量bar不可成交。

## 年度报告

每个自然年必须单独生成冷启动报告：

- 可以读取该年以前的DOGE数据作为指标warmup；
- 该年开始前始终持有现金；
- 不继承上一年仓位或复利权益；
- 信号在闭合bar决策，下一根open成交；
- 年末按最后close做MTM；未平仓必须明确标记；
- 固定报告Return、CAGR、Sharpe、MaxDD、最长回撤、闭合交易、胜率、PF、去最佳一笔和bootstrap。

## 候选选择

1. 在Discovery阶段写出机制和有限参数族。
2. 在结果未知时写预注册文件，包含通过/失败门槛。
3. Validation只能淘汰候选，不能根据结果创造新条件。
4. 在打开2025前冻结一个最终版本。
5. 2025只做一次pre-freeze audit；失败则整个版本归档，不回到参数网格。
6. 通过后才允许读取2026；读取前写入`reports/holdout_access.jsonl`。
7. 2026结果无论好坏都不修改该版本；任何修改产生新版本，而新版本不能继续把已见的2026称为holdout。

## 2026裁决最低要求

- 扣除15 bps/边后收益为正；
- 25 bps/边压力后仍为正；
- MaxDD符合预注册上限；
- 至少达到预注册最小交易数；
- 去最佳一笔后仍为正；
- episode/block bootstrap下界符合预注册门槛；
- paper与backtest逐bar target和成交时序一致。

若2026尚未积累足够交易，状态只能是`INCONCLUSIVE`，不能因为当前收益为正就判定通过。
