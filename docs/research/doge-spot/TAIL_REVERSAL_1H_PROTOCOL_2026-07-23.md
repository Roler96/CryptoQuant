# DOGE 单资产尾部条件反转冻结协议（TCR v1）

冻结时间：`2026-07-23`（在运行本候选的任何信号、收益或参数结果之前）。

> 三方向 1h 研究的**第三条(A)**，也是主候选。承接方向 C 的实测发现：单资产 1h 反转的
> 毛 edge 巨大（0bps 时 +4116% / Sharpe 1.72）但被 7027 笔换手成本吞没到 −100%——
> **约束是换手频率，不是信号有无。** 本研究检验最有经济动机的收割方式：**只在 DOGE
> 自身急跌进入尾部时做多、稀疏交易**，让每笔押注骑在一次大的反转上、把 15bps 成本摊薄。

## 研究问题

DOGE 现货在自身 N 小时急跌进入**因果尾部**（相对其自身近 90 天 N 小时收益分布的 q 分位）、
且最后一小时首次转正确认后，是否存在随后 M 小时的短期流动性反转，且净收益在 15bps/边
成本下为正。经济解释与 ISR 同源——非预测性卖单短时耗尽盘口、流动性提供者获反转补偿——
但本版本**完全单资产**：触发变量是 DOGE 自身 N 小时收益的下尾，不使用任何 BTC/ETH 残差
或市场方向过滤（遵守 `YEARLY_RESEARCH_PROTOCOL.md` 单资产边界）。

与已有研究的区分：与被 2026-07-14/15 否决的做多趋势族无关（那是牛市 beta）；与 C 的均匀
反转的区别正是**尾部条件 + 稀疏**（C 已证明均匀版被成本杀死）；不读取衍生品流（区别于
OIFR）；不使用横截面（区别于 ISR/DLC）。

## 数据与严格顺序

- 数据：仅 OKX `DOGE-USDT` 现货 1h OHLCV。**不使用 BTC/ETH/swap/funding/OI**。
- Discovery 查询在数据库层排他硬截止 `2024-01-01 00:00 UTC`；不读取 2024/2025/2026。
- 初始资金 10,000 USDT，long/cash，不借币、不加杠杆，25% 仓位；信号只读闭合 1h bar，
  下一根 1h open 成交；零成交量不成交。`Sizing.ON_ENTRY`；主成本每边 15bps，压力 25bps。

## 冻结特征

记完整小时 bar `t` 的 close 为 `C_t`，小时对数收益 `d_i = log(C_i / C_{i-1})`。

- 当前 N 小时冲击：`S_t = sum(d_i, i=t-N+1..t)`。
- 因果校准窗：严格早于当前冲击的 `L` 个小时收益 `i=t-N-L+1..t-N`，在其上取所有重叠 N 小时
  和 `P_j = sum(d_i, i=j-N+1..j)`，尾部阈值 `Q_t = numpy.quantile(P, q, method="linear")`。
- 确认：`d_t > 0`（最后一小时首次转正）。

固定 `N=6`（承接探针 6h 反转 horizon 与 ISR）、`L=2160`（90 天）、`q=0.05`。

## 冻结状态机

空仓且冷却完成时，三项须同时成立才入场：

1. `S_t < Q_t`（当前 N 小时跌幅处于自身因果 q 尾部）；
2. `S_t < 0`（确实下跌，而非分布整体上移导致的伪尾部）；
3. `d_t > 0`（若启用确认）。

触发后下一根 1h open 以权益 25% 买入，固定持有 `M=12` 根完整小时 bar 后下一 open 退出。
无止盈/止损/trailing。退出后冷却 `48h`；accepted decision 最小间隔 `M+48=60h`，保证稀疏。
持仓与冷却期间的新事件全部忽略。

## 冻结家族（5 个可交易版本，只有 main 可晋级）

- **main**：`N=6, q=0.05, M=12, confirm=True`。
- 尾部分位邻域：`q=0.025`、`q=0.10`。
- 持有邻域：`M=6`、`M=24`。

两个不可晋级消融：

- `no_confirm`：删除 `d_t>0`，其余不变（检验确认是否有用）；
- `plain_dip`：删除尾部分位（`S_t<0` 即入场，同样 hold/cooldown），检验**尾部条件相对
  无条件稀疏抄底是否真有增量**——这是本研究相对 C 的关键辩护。

不检验其他 N、L、size、止损、σ 标度或成交量过滤。`FAMILY_TRIALS = 5`。

## Discovery 晋级门（全部通过）

1. 15bps/边总收益 `>0`、Sharpe `>=0.50`、MaxDD `<=20%`；
2. 至少 20 笔闭合交易；2021–2023 至少两个冷启动自然年收益为正；
3. 25bps/边压力总收益 `>0`；静态删除最佳一笔闭合交易 PnL 后收益 `>0`；
4. episode bootstrap 10,000 次、种子 `20260723` 的 P5 `>0`；
5. 四个冻结邻域的 15bps 总收益全部 `>0`；
6. main 的 Sharpe 与 mean episode **同时**高于 `plain_dip`（尾部条件须优于无条件抄底）；
7. main 的 mean episode 高于 `no_confirm`（确认须有正增量）；
8. 按入场年份、实际持有小时、25% 仓位与相同成本匹配的 10,000 次随机入场检验，Sidak
   校正（5 个可交易版本）后单侧 `p<=0.10`。

任一失败即 `DISCOVERY FAIL`：永久归档 TCR v1，不读取 2024，不从邻域挑替代品，不调参。

## 后续年度门（若 discovery 通过）

2024 须同时：15/25bps 收益均正、Sharpe `>0`、至少 5 笔闭合交易、去最佳一笔后不为负、
匹配随机 raw `p<=0.20`。通过后 2025 用相同门。任一年度失败即永久归档，2026 不能反向挽救。

## 预先声明的限制

- DOGE 5.5 年独立制度样本个位数，功效不足是**结构性**的；即便 discovery 通过，稀疏 episode
  的证据强度有限，最终裁决以冷启动年度迁移、随机入场、成本压力与 forward 数据为准。
- 90 天校准窗内的 N 小时和高度重叠，不能当独立样本。
- close 决策/next-open 模型无盘口深度、部分成交或冲击容量；发现通过也最多是候选，且按
  [[doge-reflexivity-router-audit]] 先例，晋级最多批 shadow paper，不直接上真实资金。
