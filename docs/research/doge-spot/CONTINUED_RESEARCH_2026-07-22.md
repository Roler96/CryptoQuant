# DOGE 现货策略继续研究结论 (2026-07-22)

## 总结

继续研究没有得到可以批准真实资金的新策略。

- 冻结的 VCSE v1 通过原历史探索门槛，但在更严格的稳健性审计中为
  **`ROBUSTNESS FAIL`**。
- 由 v1 消融启发的简化 v2 历史表现更强，但在预先冻结的探索门槛中为
  **`EXPLORATION FAIL`**，因此归档，不登记为并行 forward 候选。
- 两者唯一失败项相同：相对匹配年份和持仓时长的随机入场，经过研究尝试次数校正后
  没有达到统计显著。

这次失败不是因为策略只靠某一个4h切片、某一簇相邻交易或某一个自然年；真正的问题是
DOGE 本身在少数年份、少数持仓窗口中的右尾太宽。漂亮的总收益尚不足以证明信号选择
优于在相同年份随机持有 DOGE。

## VCSE v1 强化审计

冻结 v1 不改参数，在同一组 DOGE-USDT 1h 现货数据上执行四类新审计。

### 4h bar 起点

| UTC phase | Return | Sharpe | MaxDD | Trades |
|---:|---:|---:|---:|---:|
| 0h | +383.81% | 0.95 | -38.00% | 46 |
| 1h | +146.44% | 0.63 | -39.78% | 37 |
| 2h | +1766.94% | 1.25 | -40.43% | 42 |
| 3h | +1936.18% | 1.28 | -33.68% | 45 |

四个相位全部盈利、全部 MaxDD 小于50%，说明 v1 不是只依赖 UTC 00:00 的人为K线边界；
但相位间收益差异很大，也说明不能把单一路径的 +383.81% 当成精确可复现的期望值。

### 时间聚集与年份集中

- circular block bootstrap 的 P5：2笔块 `+1.22%`、4笔块 `+21.27%`、
  8笔块 `+73.26%`；
- 逐次剔除 2021–2026 任一年，剩余 episode 复合收益仍为
  `+146.39%` 至 `+381.61%`。

所以结果并非由单一年份独占，保留相邻交易聚集后也没有立即消失。

### 匹配随机入场

对每笔真实交易固定其入场年份、持仓4h bar数量和每边15 bps成本，在相同年份随机抽取
起点10,000次：

- VCSE observed：`+383.81%`；
- random median：`-3.73%`；
- random P5–P95：`-74.27% .. +482.17%`；
- raw one-sided p：`0.067793`；
- 17次研究尝试 Sidak-adjusted p：`0.696815`。

v1 约位于该零假设的93.2分位，但连未校正的5%门槛都没有达到。原历史探索通过不被
追溯改写；新的结论是：v1 可以继续被动记录已冻结的 shadow 结果，但不应获得资金优先级。

## VCSE v2 简化探索

v2 只删除 v1 的 CLV 和 volume confirmation；压缩、突破、TR扩张、退出、成本和执行时序
全部不变。这个想法由已见的全历史消融启发，证据从一开始就是受污染的。

### 历史表现

| Metric | v1 phase 0 | v2 phase 0 |
|---|---:|---:|
| Return | +383.81% | +1616.60% |
| Sharpe | 0.95 | 1.23 |
| MaxDD | -38.00% | -38.65% |
| Closed trades | 46 | 57 |
| Less best 1 | +264.00% | +1148.45% |

v2 四个4h相位收益为 `+1589.43% .. +2185.85%`，Sharpe 为 `1.19 .. 1.32`；
50 bps/边成本后仍为 `+1051.82%`。block bootstrap、逐年 jackknife 和最小交易数都通过。

但匹配随机入场结果为：

- raw one-sided p：`0.022298`；
- 将 v2 计为第18次研究尝试后的 Sidak-adjusted p：`0.333625`。

因此必须按冻结门槛记为 `EXPLORATION FAIL`。不能用 +1616.60% 的标题收益覆盖多重尝试
问题，也不再在同一历史上继续删除过滤项或修改退出规则。

## 当前决策

1. **真实资金：不批准。** 当前没有 DOGE 现货策略通过完整证据门。
2. **VCSE v1：保持冻结、低优先级 shadow 记录。** 不调参数，不使用 no-CLV 或42-bar
   邻域；只有新闭合数据可以改变证据。
3. **VCSE v2：归档。** 不启动并行 paper，不把历史强收益解释为新发现。
4. **停止同样本迭代。** v1 实际提交冻结时间是 `2026-07-22 05:44:16 UTC`。为避免
   bar跨越冻结点，安全 forward 从 `2026-07-22 08:00 UTC` 开始的第一根完整4h bar计算，
   而不是把数据截止点之后、规则提交之前已经存在的bar追认成 OOS。另一交易所只能验证
   可移植性，不能当作独立价格路径。
5. **保持30笔 forward 裁决门槛。** v1 历史频率约每年8笔，达到门槛可能需要约3–4年；
   在此之前只报告累计状态，不做滚动参数选择。

因此当前 forward 状态是 **0个可评估bar、0个闭合交易、INCONCLUSIVE**，不能用“暂无
亏损”表述为通过。
