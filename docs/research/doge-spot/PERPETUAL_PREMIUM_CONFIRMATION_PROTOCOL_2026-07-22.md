# DOGE 永续溢价趋势确认冻结协议（PPC v1）

冻结时间：2026-07-22（在读取本候选的任何收益结果之前）

## 研究问题

检验 DOGE 永续合约相对现货的持续溢价，能否为一个简单现货上行趋势提供增量确认。
机制假设是：永续市场承载杠杆需求且可能参与价格发现；只有当连续一天的永续成交价格
显著高于自身过去基差分布、同时现货七日收益为正时，才持有小仓位 DOGE 现货。

这不是 funding carry，也不是旧研究中的负基差 V 型回收。策略不交易 swap，不收付资金费，
只把同一交易所的 swap/spot 相对价格作为状态变量。文献只支持“basis 可能含信息”和
“衍生品参与价格发现”的机制来源，并不保证本公式能预测 DOGE 现货收益：

- https://doi.org/10.1002/fut.22425
- https://www.sciencedirect.com/science/article/pii/S1057521920301502
- https://arxiv.org/abs/2212.06888

## 数据边界与顺序

- 主市场：OKX `DOGE-USDT` spot，由完整 1h bar 严格聚合为 4h。
- 辅助市场：OKX `DOGE-USDT-SWAP`，同样从完整 1h bar 聚合为 4h。
- 两个市场的 4h open timestamp 必须逐点完全一致，不允许 forward-fill。
- Discovery：`2021-01-01 .. 2024-01-01`，数据库查询硬截止并先运行。
- 主版本只有通过全部 discovery 门，才允许读取 2024 validation；通过后才允许读取 2025。
- 2026 已被其他研究消费，不用于本版本调参或挽救结论。
- 仓库旧研究已查看这些价格路径，所以后续年度只能称“候选级顺序验证”，不能称资产层面
  pristine OOS。

## 冻结公式

对每根完整 4h bar 定义成交价格基差：

`b_t = log(swap_close_t / spot_close_t)`。

当前溢价状态使用最近 6 根（24h）基差中位数：

`B24_t = median(b_{t-5}, ..., b_t)`。

因果基线刻意与当前 24h 块不重叠，使用更早的 180 根 4h bar（30d）：

`m_t = median(b_{t-185}, ..., b_{t-6})`

`mad_t = median(|b - m_t|), b in [t-185, t-6]`。

若 `mad_t = 0`，禁止信号。定义溢价分数：

`P_t = (B24_t - m_t) / mad_t`。

现货趋势为：

`M_t = log(spot_close_t / spot_close_{t-42})`（7 个自然日）。

冻结状态机：

- 空仓且 `P_t >= 1.0`、`M_t > 0`：目标变为账户权益的 25% DOGE；
- 持仓且 `P_t <= 0` 或 `M_t <= 0`：目标变为0；
- 否则维持原目标。

信号在 4h close 后产生，统一引擎下一根 4h open 成交。只做 long/cash，不借币、不加杠杆，
不使用 volume、BTC/ETH、DVR、VCSE、funding、OI 或旧策略信号。主成本每边15bps
（fee10 + slippage5），压力成本每边25bps，初始资金10,000 USDT。

## 预先登记的结构检查

四个邻域只检验稳定性，主版失败后不得替补晋级：

- 因果基线长度：120、270 根 4h bar（20d、45d）；
- 入场溢价分数：0.5、1.5 MAD。

两个机制消融不能作为候选晋级：

- `momentum_only`：删除溢价条件，`M>0` 持有、`M<=0` 空仓；
- `premium_only`：删除动量条件，`P>=1` 入场、`P<=0` 退出。

本轮可交易家族计5个版本（主版加四邻域），消融只做增量解释。旧仓库的其他公式自由度
继续披露，但不拿它们的失败替本轮降低门槛。

## Discovery 晋级门（全部通过）

1. 15bps/边收益 `>0`、Sharpe `>=0.50`、MaxDD `<=20%`；
2. 至少12笔闭合交易，2021–2023 至少两个冷启动自然年收益为正；
3. 25bps/边压力收益 `>0`，去掉最佳一笔静态 PnL 后收益 `>0`；
4. episode bootstrap P5 `>0`；
5. 四个固定邻域全部盈利；
6. 主版 Sharpe 高于 `momentum_only`，且 MaxDD 更小；
7. 主版 Sharpe 高于 `premium_only`；
8. 按入场年份和实际持仓4h数量匹配的10,000次随机入场检验，5个可交易版本
   Sidak-adjusted `p<=0.10`。

任一项失败即 `DISCOVERY FAIL`：不读取2024、不从邻域或消融挑替代版、不改变 basis 符号。

## 后续冻结门

若 discovery 通过，2024 validation 必须同时满足：15/25bps收益均正、Sharpe大于0、
至少4笔闭合交易、去最佳一笔后不为负、匹配随机入场 raw `p<=0.20`。若再通过，2025
audit 使用相同门。任一年度失败即永久归档 PPC v1，2026不能反向挽救。

## 已知限制

- swap close 与 spot close 是同一4h结束时刻的末笔成交代理，不是同步 order-book mid；
- 该 basis 混合了真实杠杆需求、微观结构噪声和瞬时套利偏差，不能等同实际 funding；
- MAD 标准化只抵消长期尺度变化，不能修复交易所合约制度或流动性突变；
- 消融比较能检验历史增量，不能证明溢价是因果资金流；
- 当前统一引擎外部 Donchian 校准门仍为 FAILED，即使研究通过也最多进入 shadow paper。
