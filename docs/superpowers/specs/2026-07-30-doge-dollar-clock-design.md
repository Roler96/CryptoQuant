# DOGE 现货 5m：成交额时钟坐标系变换（Dollar-Clock Coordinate Shift）

- 日期：2026-07-30
- 标的：`DOGE-USDT` 现货，5m
- 数据约束：**只用 DOGE 现货 5m**。不引入永续、BTC、funding、open interest。
- 状态：设计（未实现）

## 1. 问题陈述

这个仓库对 DOGE 做过十几轮单资产择时研究，全部失败：

| 家族 | 结局 |
|---|---|
| 1h 反转（均匀 / 尾部条件 / DVR 精化） | 三条全 DISCOVERY FAIL；RFS 沿频率光谱扫 7 点处处 null → **整族 CLOSED** |
| 做多趋势 / TSMOM | locked test −34%，判定为牛市 beta，黑名单 |
| 5m 冲击延续（SIC） | −90.7%，随机检验 p = 1.0 |
| 现货-永续基差冲击回归（BSR） | 20 笔且全堆 2021，样本门 FAIL |
| 注意力冲击延续（ASC） | 管线自检显示消融强于 main，开闸前已预判死于"残差剥离无增量" |

诊断这些失败时反复出现三堵墙：

1. **功效墙**：DOGE 右尾极宽，毛收益打不过"同年同持仓的随机 DOGE 持有"
2. **成本墙**：换手率是外生设定的（事件触发 → 固定仓位 → 固定持仓期），15 bps/边直接吞掉毛 edge（均匀 1h 反转毛 +4116% → 净 −100%）
3. **样本墙**：事件触发器把 46 万根 bar 压缩成几十到几百个稀疏样本

**本设计的核心论断**：这十几次不是十几个独立的失败，而是同一个结构问题的反复显影——**所有策略都活在同一个坐标系里：日历时间 × 收盘价 × 常数成本**。未开采的信息全在这个坐标系的正交补上。

## 2. 核心假说

### 2.1 时间轴：日历时间是错误的自变量

实测 explore 窗成交额分布（DOGE-USDT 5m）：

```
p1     2,163        p50   127,002       p99  5,981,545
p5     7,750        p75   377,037       p99.9 20,619,222
p25   40,666        p95 1,851,293       max  131,612,597   USDT / 5m

p99 / p50 = 47x，全域跨 4~5 个数量级
```

一根深夜 bar 承载 2,163 USDT，一根暴动 bar 承载 1.31 亿——相差近 6 万倍，却被当作同一个观测单位喂进同一条规则。

**推论**：一个在事件时钟上稳定的效应，投影到日历时钟上会被时变的活跃度做**随机相位化**，然后被平均掉。这一句话同时解释了 RFS 扫 7 个频率处处 null、邻域 6/6 → 1/6 崩塌、5m 延续 −90.7%。它们不是七个独立的坏运气，是同一个投影误差的七次显影。

**附带推论（本设计的原创点）**：在成交额时钟上，"放量"这个变量**消失了**——每根 bar 定义上等额。信息不会凭空消失，它守恒地转移到了**桶的日历时长 Δt** 上。`1/Δt` = 信息到达强度，且与价格方向完全解耦。**「桶的日历时长」这个变量在本仓库全部历史研究中从未作为特征存在过。**

### 2.2 价格轴：close 是样本量为 1 的估计量

所有历史策略用 `close`——bar 的最后一个 tick。而 `quote_volume / volume` = bar 内成交量加权价格重心（VWAP），是同一根 bar 上信息量高得多的统计量。

实测（DOGE-USDT 5m，explore 窗）：

```
VWAP 位置 (VWAP−L)/(H−L)   均值 0.4986   std 0.1236   合法率 0.999997
与 close 位置 (C−L)/(H−L) 的相关系数   0.1415
```

**相关仅 0.1415** → 这一维与本仓库全部历史研究用过的信息近乎正交。

定义 `δ = (C − VWAP) / (H − L) ∈ [−1, 1]`。机制读法：

- δ 大：bar 末尾出现了**成交量没跟上的推动**，价格跑在成交额前面 → 流动性滑移，预期回补
- δ 小：位移被成交量确认 → 真实重定价

这是微观结构机制，不是形状拟合。

### 2.3 成本轴：成本墙一直被当成常数

真实有效价差可以直接从 5m 的 high/low 估出（Corwin–Schultz 类高低价估计量）。成本一旦成为**状态变量**，"只在价差处于低分位时交易"就能直接压低成本墙——不需要信号变强。

### 2.4 三层的咬合（及其待验证前提）

> 把 DOGE 现货 5m 从「日历时间 × 收盘价 × 常数成本」整体搬到「成交额时间 × 成交重心 × 时变价差」，再问同一个老问题。

咬合点：成交额时钟让换手在日历上自适应（活跃时多调仓、冷清时不动），而冷清时正是价差最宽的时候——时钟层与成本层的最优行为自动一致。

**这是假设，不是事实。** D4 必须直接检验 `价差 ~ Δt` 的关系。若不成立，咬合叙事必须改写，不得蒙混。

## 4. D 阶段：坐标系诊断

### D0. 数据契约

- 源：`ohlcv`，`inst_id='DOGE-USDT'`，`timeframe='5m'`
- 窗口：explore 窗 `ts ∈ [2021-01-01, 2025-06-01)`。**validate 窗不碰。**
- 使用列：`ts, high, low, close, volume, quote_volume`
- `open` **不作为特征**（连续序列里 open ≈ 前一根 close，冗余），仅用于数据健全性交叉检验
- **连续性断言**：根数必须等于 天数 × 288。缺一根即拒跑并上报，不做近似填补
- **零量 bar 处理**（explore 窗全域 281 根，多为 OKX 停机打印的合成平盘 bar）：
  - 对成交额时钟贡献 0 成交额，自然被吸收进相邻桶
  - 其收益标记为缺失
  - **日历序列与成交额序列使用同一套缺失规则**，否则配对不干净
- **指纹**：全表 SHA256 写入 PROTOCOL；后续任何 run 必须复现同一指纹

统一定义（避免下游歧义）：

- **收益**：`r_t = log(C_t / C_{t−1})`，对数收益。选它是因为跨尺度可加——日历聚合与桶聚合下的收益定义必须自洽，简单收益做不到
- **δ**：`δ = (C − VWAP) / (H − L)`，其中 `VWAP = quote_volume / volume`。当 `H = L`（bar 内无价格波动）时定义 `δ = 0`
- **方向命中率**：`r = 0` 的样本对从统计中剔除（平盘 bar 无方向信息），并报告剔除比例

### D1. 时钟构造

对每个尺度 `s ∈ {15m, 1h, 4h, 12h}`：

- **日历序列 `C_s`**：5m bar 按 3 / 12 / 48 / 144 根聚合，得 `N_s` 根
- **成交额序列 `D_s`**：贪心扫描 5m bar，累计 `quote_volume ≥ V_s` 时封桶

封桶规则（预先定死，不留自由度）：

1. 封桶发生在**累计首次达到或超过 `V_s` 的那根 5m bar 结束时**。不做 bar 内切分——5m 是采样下限。
2. **溢出量不结转**到下一桶。等价表述：每个桶 = 「累计成交额 ≥ `V_s` 的最小 5m 连续块」。
3. 序列末尾不足 `V_s` 的残桶丢弃。

**5m 尺度被排除（数学退化，不是数据特性）**：样本量匹配要求成交额桶数等于 bar 数，而每桶至少含一根 bar，于是每桶恰好一根——成交额时钟与日历时钟的划分**逐位恒等**，`Δ_s ≡ 0`，零分布方差为零。已实测确认（factor=1 时 `edges == arange(1, n+1)`，与日历划分 bit-for-bit 相同；factor ≥ 2 均不退化）。故尺度阶梯取 `{15m, 1h, 4h, 12h}`，最细尺度为 15m。

**样本量匹配**：因溢出，每桶平均成交额 > `V_s`，朴素取 `V_s = 总额 / N_s` 会导致 `M_s < N_s`，破坏配对前提。修正：对 `V_s` 做二分搜索使 `M_s → N_s`。确定性、零自由度。

`M_s` 是整数而 `V_s` 连续，无法保证精确相等。**收敛容差预注册为 `|M_s − N_s| ≤ max(1, 0.001 · N_s)`**；二分搜索上限 100 次迭代，取区间内使 `|M_s − N_s|` 最小的 `V_s`。RESULTS 报告每个尺度实际达到的 `M_s`、`N_s` 与 `V_s`。

桶的 OHLCV 由成员 5m bar 聚合：`O` = 首根 open，`H` = max，`L` = min，`C` = 末根 close，`V`/`QV` = sum。同时记录**桶的日历时长 `Δt`**。

**保真度硬伤（必须量化并报告，不得隐藏）**：5m 是采样下限，桶边界只能落在 5m 边界上。p99.9 的一根 5m bar 承载 2,062 万 USDT，若目标桶约 48 万，这一根自身就超额 40 倍且无法细分；反之 p1 的 bar 仅 2,163 USDT，需聚合约 230 根（19 小时）才凑满一桶。因此成交额时钟是**近似**的，两端误差最大。RESULTS 必须报告：`M_s / N_s`、桶实际成交额相对 `V_s` 的分布（p5 / p50 / p95）、单根 5m 超额桶的占比。

### D2. 测度（每尺度 × 每时钟各算一遍）

| 类别 | 测度 | 角色 |
|---|---|---|
| 非参数 | Spearman 秩自相关 ρ_S(lag = 1..5) | **主判据** |
| 非参数 | 方向命中率 sign(r_t) → sign(r_{t+1}) | **主判据** |
| 非参数 | Spearman(δ_t, r_{t+1}) | **主判据** |
| 参数 | 方差比 VR(q)，q ∈ {2, 4, 8} | 佐证 |
| 参数 | OLS R²：r_{t+1} ~ δ_t | 佐证 |
| 参数 | 峰度 | **健全性检验** |

主判据用非参数的理由：DOGE 右尾极宽，二阶矩量会被极少数极端 bar 主导，这正是功效墙的技术根源——不是效应不存在，而是**度量本身被肥尾吃掉了功效**。

参数度量同时报告作佐证。**两套背离时不当作失败，而是写进结论**：背离本身说明"信号存在但被尾部吞掉"，这是可操作情报，直接导向 C 层的尾部风控。

### D3. 配对差分与零假设

主统计量：`Δ_s = 测度(D_s) − 测度(C_s)`，每尺度一个。

配对设计的功效来源：RFS 是在日历时钟上扫 7 个频率、每个独立问"有没有 alpha"（Šidák 惩罚重，功效被稀释）；本设计在每个尺度上做「日历 vs 成交额」**同尺度对照**，看的是**增量**。共同的市场噪声在配对内被抵消，即使每个尺度上两者都 null，增量仍可能系统性偏离 0。判据是符号一致性而非最大值，天然免疫"挑赢家"。

**零假设构造——两类主测度各配一个恰当的 null**：

| 主测度 | 零假设 | null 构造 |
|---|---|---|
| 秩自相关、方向命中率 | 收益的时序结构与成交额划分无耦合 | 平稳 block bootstrap 重排 **5m 收益序列**，成交额序列冻结不动 |
| δ 预测力 | δ 与未来收益无耦合 | 平稳 block bootstrap 重排 **δ 序列**，收益与成交额**都不动** |

第一个 null 保持两个时钟的桶划分完全不变，只打断「收益 ↔ 成交额」的耦合。第二个 null 更干净：时钟划分与收益路径完全原样，只打断待检验的那一条耦合。

> 设计注记：曾考虑用单一 null（重排收益、冻结成交额）覆盖全部测度，但那会使 δ 在 null 下变成混合物——`C` 来自重排后的价格路径，而 `H`/`L`/`VWAP` 仍来自原始数据，检验不干净。故分设两个 null。

Bootstrap 次数 `B = 2000`。

**block 长度预注册规则**（避免"跑完再挑"）：取 5m 对数收益的 |自相关| 首次落入 ±2/√n 置信带的 lag，向上取整到 12 的倍数（即整小时）。该值一经从 explore 窗算出即**冻结并写入 PROTOCOL**，跑完后不得调整。

### D3 闸门（预注册）

四尺度的 bootstrap p 用 Stouffer 方法合并。因 null 是联合生成的，合并统计量的 null 分布可直接在 bootstrap 内计算，跨尺度相关性自动处理。

- **G1 主检验**：三个主测度中任一的 `p_combined ≤ 0.0170`（Šidák 校正，3 个主测度，family α = 0.05）
- **G2 健全性**：峰度在 ≥ 3/4 尺度上下降。这是 dollar bar 的已知性质——**不降说明时钟实现有 bug，整个诊断作废重做**，而不是当作结论
- **G3 方向一致性**：过关测度的 `Δ_s` 在 ≥ 3/4 尺度**同号**，防止单个尺度的极端值撑起合并 p

三门全过 → 进 S 阶段。任一门失败 → 写 RESULTS，判 CLOSED。

### D4. 附加诊断（不设门，为 S 阶段供料）

1. **★ 咬合前提检验**：用 Corwin–Schultz 从 5m 高低价估时变有效价差，直接检验 `价差 ~ Δt` 的关系。这是 §2.4 咬合叙事所依赖的、**尚未验证的假设**。若不成立，叙事必须改写

4. δ 与 close 位置的相关在各时钟上复核（日历 5m 上已实测 0.1415）

## 5. S 阶段：策略构造

S 阶段的形态**取决于 D 的结果**——哪个测度活下来，预测层就用哪一维。下面是骨架加条件分支。

### S1. 状态空间

策略活在成交额时钟上，每封一个桶做一次决策。换手率的日历分布不是参数，是市场活跃度的函数。

### S2. 预测层

在成交额时钟上估下一桶收益的条件期望 `μ_t` 与条件方差 `σ²_t`。

**特征池预注册为闭集，不允许事后追加**：

- `δ_t`
- 桶日历时长 `Δt_t`（含 `log Δt` 与变化率）
- 秩化的过去 k 桶收益
- Corwin–Schultz 价差 `s_t`

**模型：秩变换 + 线性。** 理由不是保守——主判据本就落在秩空间（非参数）；线性模型自由度可数、可审计、抗过拟合。在此信噪比下用树模型或神经网只会拟合噪声，且**审计不了**：本仓库有三次前视 bug 是靠逐位复现抓出来的，不可审计的模型等于放弃那道防线。

### S3. 仓位层（成本内生）

```
w* = clip( μ_t / (λ · σ²_t), 0, 1 )        纯现货多头，无杠杆、不做空
调仓条件：预期收益改善 > 2 · s_t（往返成本），否则留在无操作带内不动
```

`s_t` 是 D4 估出的**时变**价差，不是常数 15 bps。换手率不是参数，而是 `μ`、`σ`、`s` 三者的函数。这是"成本内生"的确切含义，也是对成本墙的正面回应。

### S4. 基准（直击功效墙）

不与 0 比较。预注册三条，**必须全部打败**：

- **B1** DOGE 现货 buy & hold（同期）
- **B2** 匹配随机入场：同样的换手次数、同样的持仓时长分布，入场时点随机。这是杀死历史十几个策略的那把刀，本策略先自己挨一刀
- **B3** 常数仓位 buy & hold（`w` = 策略平均仓位），剥离"只是仓位小所以回撤小"的假象

### S5. 消融（预注册）

"三层咬合"可能实为一层有用、另两层是复杂度装饰。ASC 就是被"消融强于 main"预判死的。main 必须打败全部三个消融：

- **A1** 同策略跑在日历时钟上 → 剥离 A 层
- **A2** `δ` 换成 close 位置 `(C−L)/(H−L)` → 剥离 B 层
- **A3** 成本用常数 15 bps 而非时变 `s_t` → 剥离 C 层

**A1 输了尤其致命**：意味着整个坐标系论断是错的，即使策略赚钱也不该信。

### S6. explore 窗内的调参纪律

自由参数仅 `λ`（风险厌恶）与特征子集选择。预注册切分：

- `λ` 在 **2021-01 → 2023-06** 标定
- **2023-06 → 2025-06** 作 explore 内 OOS，**后半段不调任何东西**

- **★ bootstrap null 元测试**：在**纯随机游走数据**上跑完整 D 流水线，`p` 值必须近似均匀分布（KS 检验）。这是能抓出 null 构造 bug 的唯一硬手段——没有它，D 阶段的全部显著性都是空的
- **G2 峰度健全性**同时充当时钟实现的运行时自检
