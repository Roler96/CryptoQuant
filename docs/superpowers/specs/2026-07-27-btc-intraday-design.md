## 1. 目标与成功标准

**交付一个可进模拟盘的双资产日内候选，外加一份能在 validate 窗做出裁决的预注册协议。**

用户明确选定"必须产出可实盘候选"作为这一轮的终点（而非"裁决优先"）。这个目标被结构化
地保护：**可实盘不等于放低证据门槛**，而是意味着挑先验概率更高的方向去做，并明确标注
候选的证据等级。若 §6 的门未过，正确结果是候选降级或关闭，不是放行。

### 3.2 成本墙

BTC 1h explore：`std = 66.7 bps`，`mean|r| = 41.4 bps`。

把 `E|r_h|` 换算成"要净赚，方向准确率至少得多少"，即 `p > 0.5 + 成本/(2·E|r_h|)`：

| 持仓 | E&#124;r&#124; | 现货 15 bps/边 | 永续 7 bps/边 |
|---|---|---|---|
| 1h | 41.4 bps | 86.2% | 66.9% |
| 2h | 58.9 | 75.5% | 61.9% |
| 4h | 83.8 | 67.9% | 58.4% |
| 6h | 103.0 | 64.6% | 56.8% |
| 8h | 119.9 | 62.5% | 55.8% |
| **12h** | **150.1** | 60.0% | **54.7%** |
| 24h | 220.4 | 56.8% | 53.2% |

顶级做市商约 52–55%。**结论：现货口径下 BTC 日内数学上接近不可能（24h 持仓仍需
56.8%）；永续口径下 6–12h 才进入可能区间。** 这条约束单独决定了 §5 的市场选择。

**注意成本墙公式假设赢输幅度对称**。§3.5 的候选胜率仅 52.9%、低于表中 54.7%，却仍净
赚 29.3 bps——因为其**赢面幅度大于输面**。故本表是筛方向的先验工具，不是判定门。

### 3.3 时段与星期效应：可作条件变量，不可作信号

24 个 UTC 小时的平均 1h 收益落在 `−2.4 ~ +3.1 bps`，最大 `|t| = 1.85`（24 格多重检验后
无意义），远小于 14 bps 往返成本。星期效应同样为零。**"BTC 日内有时段规律"这条路
在数据上不存在，判定关闭。**

但波动率与成交量的日内结构真实且机制明确：

| 时段 | std | 相对成交量 |
|---|---|---|
| h12–h16（美股时段） | 74–91 bps | 1.19–1.54× |
| h4–h7（亚洲午后） | 50–59 bps | 0.80–0.85× |
| 周六 / 周日 | 49.3 / 54.8 bps | — |
| 工作日 | 66–76 bps | — |

周末波动率比工作日低约 30%——CME 关闭、ETF 不申赎的直接印证。该结构进入 §7 的机制
诊断，**不进入 main 的信号**。

### 3.4 微观反转关闭

BTC 1h lag-1 自相关 `ρ = −0.0066`，`n = 38,679` → 约 1.3σ，**不显著**。对比 DOGE 5m 的
`ρ = −0.0386`（26σ）。**BTC 1h 没有微观反转结构，该方向关闭。**

### 3.5 核心发现：冲击延续（与 DOGE 方向相反）

冲击定义：`|r_t|` 超过 trailing 168 根（7 天，严格早于 t）的给定分位，出场后冷却 12 根
使事件成为独立 episode。对**匹配随机入场**（同年、同笔数、同持仓长度、同多空配比）：

**第一轮（单向扫描，close-to-close，24 格）**，最强格：

| 方向 | 分位/持仓 | n | 超额 | p | 逐年超额 |
|---|---|---|---|---|---|
| DOWN | q99 / 12 | 224 | **−42.5 bps** | 1.0000 ← 反向即 p<0.0005 | 21:−98 22:−54 23:+17 24:−65 25:+3 |
| UP | q99 / 12 | 225 | +35.7 bps | 0.0075 | 21:+73 22:−21 23:+27 24:+54 25:+34 |

**DOGE 的 DIR 机制在 BTC 上不成立且方向是反的**：DOGE 下行冲击后回补（强平级联→流动性
枯竭→过冲→回补），BTC 下行冲击后**继续跌**。物理图景自洽——`hold 24` 时 DOWN 超额翻正
（+5.5），延续在约 12 小时后耗尽。

**第二轮（双向对称，9 格）**：顺冲击方向交易两侧，消掉"挑了哪一侧"的自由度。

| 窗口 | 分位/持仓 | n | 超额 | p | 逐年超额 |
|---|---|---|---|---|---|
| 全 explore | q99 / 12 | 377 | **+44.7** | **0.0005** | 21:+81 22:+31 23:+19 24:+56 25:+19（**5/5 正**） |
| 前半 21–23 | q99 / 12 | 191 | +51.3 | 0.0047 | 3/3 正 |
| 后半 23–25 | q99 / 12 | 186 | +37.1 | 0.0025 | 3/3 正 |

**前后半各自独立显著且方向一致。** 另一个正面迹象：q99 是三个分位里最宽松的
（n 最大），却最强；q99.9 的逐年是 21:+109 22:−13 23:+7 24:+90 25:−48（3/5）。
**更多样本 → 更强信号**，是真实效应的特征；过拟合通常相反。

**第三轮（可执行时序 + 实际交易的标的）**：信号读闭合 bar `t`，`t+1` open 建仓，
`t+1+12` open 平仓。

| | `BTC-USDT-SWAP` @7bps | `BTC-USDT` 现货 @15bps |
|---|---|---|
| n（多/空） | 380（192/188） | 377（190/187） |
| 毛 / null / 超额 | 43.3 / 1.0 / **+42.3** | 45.6 / 0.7 / +44.9 |
| p（4000 次匹配随机） | **0.0005** | 0.0002 |
| **净均值** | **+29.3 bps** | +15.6 bps |
| 胜率 | 52.9% | 49.6% |
| 去最佳一笔 | 25.9（几乎不掉） | 12.2 |
| 逐年净 | +63.8 / +16.4 / +4.4 / +41.4 / +6.1 → **5/5** | +51.7 / +2.0 / −9.6 / +26.6 / −9.8 → 3/5 |
| bootstrap P5 | **+7.1 > 0** | **−6.9 < 0** |

**现货口径下本候选是 FAIL 的**（bootstrap P5<0、2/5 年负）；永续口径下全部通过。
§3.2 的成本墙推论被直接印证。

### 3.6 跨资产复制：效应集中在大盘，不普适

同一规则零调参迁移到全部 21 个 `*-USDT-SWAP`（各用自己的 trailing 分位，无任何按资产
调参）：

- **13/21 超额 > 0** → 符号检验 `P(X≥13) = 0.19`，**不显著。这不是普适机制。**
- `p<0.05` 的仅 4 个：**BTC 0.0013、ETH 0.0027**、SOL 0.047、UNI 0.046
- **BTC 与 ETH 是唯二逐年 5/5 正的**，超额 +42.2 / +49.1
- 明确为负：LINK −27.2、XRP −30.9、COMP −23.2、AAVE −17.2、ALGO −14.8、ATOM −11.2

（BTC 在此为 p=0.0013 而 §3.5 为 0.0005，差异仅来自抽样次数 1500 vs 4000。）

**ETH 的零调参复制是本设计最有价值的独立证据**：独立资产、参数一个没动、同样 5/5 年正。
ETH 在可执行时序下毛均值 49.6 bps，扣 14 bps 往返后**净 +35.6 bps**，高于 BTC 的 +29.3。

**事后机制假说（必须标注为事后）**：效应集中在有 CME 期货、现货 ETF、机构参与的大盘
资产上，山寨没有——冲击后的价格发现要在多个市场间传导，需要时间；山寨主要是散户强平
的即时出清。**这个解释是看到结果后编的**，其可证伪推论进入 §7 诊断，不进入 main。

### 3.7 事件重叠度：双资产贡献多少独立样本

| 量 | 值 |
|---|---|
| BTC / ETH 事件数 | 380 / 379 |
| ETH 事件与 BTC ±1h 同时发生 | 174 / 379 = **45.9%** |
| 共振事件中方向相同 | 169 / 174 = 97% |
| **膨胀比 `I` = 759 事件 / 585 簇** | **1.30** |

**DOGE 设计的膨胀比判据（`I < 1.5` 独立 / `I ≥ n/2` 高度共振）在 `n=2` 时退化**：
`n/2 = 1.0` 而 `I` 的下界就是 1.0，任何取值都会被判"高度共振"。该判据是为 `n=12/20`
设计的，此处不适用。改用直接量：**45.9% 重叠，即过半 ETH 事件独立**，有效样本介于
380（全共振）与 759（全独立）之间，簇数 585 是它的正确估计。

**统计量因此必须用簇稳健方法**（重抽簇而非事件，保留同簇跨资产相关结构）。

| 组合 | n | 净均值 | 胜率 | bootstrap P5 |
|---|---|---|---|---|
| BTC 单资产 | 380 | +29.3 bps | 52.9% | +7.1（逐事件） |
| **BTC+ETH 等权** | 759 / 585 簇 | **+32.4 bps** | 52.0% | **+10.3（簇稳健）** |

### 3.8 权益曲线（0.25 权重，粗算）

| 指标（4.41 年） | 值 |
|---|---|
| 总收益 / 年化 | +78.0% / **+14.0%** |
| MaxDD | **−15.4%** |
| Sharpe | **1.05** |
| 逐年 | +35.1 / +4.0 / +1.6 / +13.6 / +9.7 → 5/5 正 |

年化 14.0% 与事件研究独立算出的 13.9%（32.4 bps × 172 笔/年 × 0.25）吻合到 0.1 个
百分点——两条独立路径的交叉验证。

**这条曲线的第一版是错的**：`ret[i] = log(open[i]) − log(open[i−1])` 配 `pos[i]`，
整体错位一格，仓位乘上了建仓前已发生的收益，是前视；错误版本给出年化 256%、
Sharpe 7.37、MaxDD 仅 5.7%。**教训直接进入 §10 的测试要求**：粗算脚本不能替代引擎
回测，§6 的所有数字必须由 `cq/engine` 产出。

**`main` 是我从看过的结果里挑的。** 搜索账：

|---|---|---|
| 1 | 2 方向 × 3 分位 × 4 持仓（单向） | 24 |
| 2 | 3 分位 × 3 持仓（双向对称） | 9 |
| 3 | 前后半分裂 | 4（诊断，不选参） |

| — | `TRAIL=168`、`COOL=12` | 未扫描，由 DOGE 的日历跨度直接映射 |

**主家族 `N = 33`**（轮次 1+2）。`main = q99 / hold12` 从中挑出。

**后果**：

1. **explore 窗的发现门降级为工程检验**——只证明实现正确、成本墙过得去、逐年不崩溃。
   它**不是**"这不是运气"的证据。
2. Šidák 校正：`p = 0.0005`，`N = 33` → `p_adj = 1 − (1−0.0005)^33 = 0.0164`，**仍显著**。
   这是本候选与 DOGE 全家族的关键区别（后者校正后普遍 p > 0.4）。
3. **"这不是运气"的独立证据有两条**：ETH 零调参复制（§3.6）与前后半分裂（§3.5）。
   两者都不消耗 main 的自由度。
4. **validate 窗只测 main，不测邻域**。邻域仅在 explore 上跑作稳健性展示，不参与裁决。

## 5. 冻结的主规则（此刻定死）

| 项 | 值 |
|---|---|
| 标的 | `BTC-USDT-SWAP` + `ETH-USDT-SWAP` |
| 时间框架 | 1h |
| 触发 | `\|r_t\|` > trailing 168 根（严格早于 `t`，当前 bar 绝不进入自己的基线）的 **q99** |
| 方向 | `sign(r_t)`——顺冲击方向，多空对称 |
| 成交 | 信号读闭合 bar `t`；`t+1` open 建仓；`t+1+12` open 平仓 |
| 持仓 / 冷却 | 12 根 / 实际出场后 12 根 |
| 目标集合 | 每腿 `{−0.25, 0, +0.25}`，**无杠杆** |
| Sizing | `ON_ENTRY`；初始 10,000 USDT；逐 bar MTM；末尾未平仓显式强平并标注 |
| 成本 | 主 **7 bps/边**（fee 5 + slip 2）；压力 **12**；极端 **25**（仅披露，不设门） |
| funding | 每跨一次 8h 结算点计 **1 bps，不分方向** |

**两腿是独立状态机**，各用自己的 trailing 分位，**没有任何参数按资产调整**——ETH 的
复制正是靠零调参才有证据价值，实盘必须保持。

**funding 处理的理由**：explore 窗无 funding 数据。多空对称策略下 funding 近似中性
（多头付、空头收），故"不分方向一律计支出"是**偏保守**的处理。真实 funding 数据可用
后（2026-04 起）在 validate 窗做敏感性复核。

**极端档 25 bps/边不设门**的理由：q99 冲击 bar 就是流动性最差的时刻，2 bps 滑点假设在
那种 bar 上未必成立。RESULTS **必须**明写该档下的结果，并在实盘前实测冲击 bar 的真实
滑点。附加 `slippage = min(10 bps, k × bar_range)` 的敏感性诊断作为附录。

**预声明邻域 `FAMILY_TRIALS = 6`**，每版与 main 只差一个轴：
`q995` / `q999` / `hold8` / `hold24` / `trail336` / `cool24`。**不得挑赢家替换 main。**

## 6. 预注册判定门

### 6.1 explore 窗（工程检验，因 §4 降级）

1. 主成本 7 bps 净收益 > 0
2. 压力 12 bps 净收益 > 0
3. 逐年 ≥ 4/5 年为正
4. 去最佳一笔后仍为正
5. **簇** bootstrap P5 > 0
6. 匹配随机入场 Šidák 校正（`N=33`）后 `p < 0.10`
7. 6 个预声明邻域中 ≥ 4 个净收益为正
8. MaxDD ≤ **25%**（先验风险承受标准，非由观察值反推；explore 粗算为 15.4%）
9. **无 `gap_chased_entry` 标志**——含此标志的 run 不得 PASS

### 6.2 validate 窗（真正的裁决）

**功效声明（读取前写死）**：per-episode `σ ≈ 336 bps`（双资产）。validate 窗事件率按
explore 的 172 事件/年外推：

| 可读区间 | 日历 | 事件 | 簇 | 标准误 | 效应 32.4 bps 的 t | 功效 |
|---|---|---|---|---|---|---|
| 2025-06 → 2026-07（当前） | 1.15 年 | ~198 | ~152 | 27.3 bps | 1.19 | **32%** |
| 2025-06 → 2027-06（完整） | 2.00 年 | ~345 | ~266 | 20.6 bps | 1.57 | 47% |

**当前可读区间功效仅 32%，完整窗也只有 47%。因此"读不出显著性"不得被解读为证伪。**
门槛据此设为
方向一致性而非统计显著：

1. 主成本净收益 > 0
2. 簇 bootstrap P5 > 0
3. 达到最小事件数 **≥ 150**（否则只能报 `INCONCLUSIVE`）
4. 分年/分季分解中 ≥ 2/3 为正
5. BTC 与 ETH **两腿各自**净收益 > 0（单腿撑起全部收益即判失败——那说明不是同一机制）

**最终裁决等 2027-06 完整窗。** 在此之前状态为 `PROVISIONAL`，只能支撑 shadow paper，
不得投入真金。

## 7. 机制诊断（预注册，只报告不设门）

§3.6 的机制解释是事后的。以下分解检验其可证伪推论，**在 explore 与 validate 窗都报告，
但不参与任何选择**：

| 诊断 | 假说预测 |
|---|---|
| 按 UTC 时段分解超额（h13–h21 vs h0–h8） | 美股时段更强 |
| 按星期分解（工作日 vs 周末） | 周末更弱（CME 关闭） |
| 按方向分解（UP vs DOWN） | 两侧同号 |
| 按共振分解（BTC/ETH 同时 vs 单独触发） | 共振事件更强（市场级信息） |
| DIR 严格移植到 BTC 5m（DOGE 冻结参数，`N=1`） | 预期失败——回答"DOGE 机制是否 BTC 特异" |

若时段/周末诊断与假说相反，RESULTS 必须记录"机制解释未获支持，候选仅有统计证据"。

## 10. 测试要求

**策略层**：warmup；trailing 分位边界（当前 bar 绝不进自己的基线）；状态机（持有 12 /
冷却 12）；多空双向目标；零量 bar；缺 bar 立即 raise；`ON_ENTRY` 语义；两腿独立性；
快照往返。

**统计层**：簇聚类用构造的已知重叠模式验证；簇 bootstrap 的重抽单位必须是簇而非事件；
符号检验。

**前视专项**（§3.8 的教训）：构造一个已知答案的合成序列，验证权益曲线的仓位-收益对齐
——`pos[j]` 必须只吃 `open[j+1] − open[j]`。粗算脚本的错误版本给出 Sharpe 7.37，
正确版本 1.05；这个 6 倍差距就是前视的量级。

**验证测试有效性时**：改坏源码必须 `PYTHONDONTWRITEBYTECODE=1` + 补丁自检——本仓库
踩过 pyc 缓存导致假绿的坑。

## 11. 预期失败模式

1. **引擎回测推翻粗算** → §3.8 的数字来自简化脚本，真引擎含滑点建模、部分成交、
   保证金占用，结果可能显著更差。这是最可能的失败模式。
2. **极端滑点档下全负** → 死于成本墙，q99 冲击 bar 的真实滑点是最大未知数。
3. **validate 窗功效不足读不出** → 已在 §6.2 预先声明，不得解读为证伪，只能挂起等
   2027-06。
4. **单腿撑起全部收益** → 由 §6.2 门 5 捕获，说明不是同一机制。
5. **机制诊断与事后假说相反** → 候选降级为纯统计发现，可信度下降但不自动关闭。
6. **2022 熊市的表现是运气** → 逐年门与前后半分裂已部分防护，但样本仍只有一个熊市。
