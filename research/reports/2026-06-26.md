### 2. Swing Pivot Breakout = Breakout Family #4 Achieving 4/4 Main Gate
Swing pivot detection joins DualThrust (Loop 17), BB %B (Loop 11), and Range Expansion (Loop 5) as breakout strategies achieving universal parameter robustness (4/4 main gate pass). Unlike channel-based breakouts (Donchian, BB, Keltner), swing pivots represent structural support/resistance levels — market-agreed price levels rather than statistical boundaries.

### 3. 4h OOS Failure — Now Confirmed 14+ Instances Across 8 Loops
Both strategies fail 4h OOS validation (all 4 combos). Root cause is not signal quality (BTC 4h OOS Sharpe=1.98-2.70, ETH 4h OOS Sharpe=0.69-3.01) — it's sample size. IS windows contain only 23-29 trades; OOS windows contain 12-16 trades. The OOS gate requires ≥30 trades in a 730-bar window, which is physically impossible on 4h for strategies generating 40-44 trades/year total.

**Updated tally:** 4h OOS failures now span Williams %R, Swing Pivot, Fisher Transform (Loop 18), Efficiency Ratio (Loop 18), CMO (Loop 12), AO (Loop 13), CMF (Loop 14), MFI (Loop 14), HMA (Loop 12), UltOsc (Loop 12), KAMA (Loop 10), PSAR (Loop 9), SuperTrend (Loop 11), MacdAdx (Loop 5). **Only DualThrust (136 trades on 4h) has ever passed 4h OOS** — because trade count exceeds the 30-trade OOS minimum.
